# Product

プロダクト定義（概要・ビジョン・基盤）。画面・IA は [design.md](./design.md) を参照する。実装チケットは [backlog.md](./backlog.md) を参照する。

# 1. 概要

## 1.1 プロダクト概要

本アプリは、ユーザーが自分だけのスタンプラリーを作り、日常で「人に会った」「場所に行った」「何かをした」ときにそのラリーへスタンプを押して集めていくモバイルアプリである。

一般的なライフログのように詳細な情報を入力・管理することを主目的とはせず、日常の出来事を「集める」「達成する」という体験へ変換することを重視する。

流れは次の2段階である。

1. **ラリーを作る**: 集めたいテーマに名称を付け、タイプ（人 / 場所 / 行動）を決める。例: 「今年会った研究者」（人）
2. **スタンプを押す**: 実際に体験したときに、そのラリーを選んでワンタップでスタンプを押す。記録の本体は日時。例: 「今年会った研究者」のラリーを押す

押したスタンプはラリーごとに集まり、時系列やカレンダーからも振り返ることができる。

## 1.2 プロダクトビジョン

**日常を、自分だけのスタンプラリーにする。**

ユーザー自身が何を集め、何を達成とするかを自由に決められることを基本思想とする。

運営側があらかじめ体験や達成条件を定義するのではなく、ユーザー自身の生活・興味・目標に合わせて記録と収集を行えるプロダクトを目指す。

## 1.3 対象ユーザー

日常の体験を気軽に記録したい個人を対象とする。

特に、以下のようなニーズを持つユーザーを想定する。

- 出会った人を記録したい
- 行った場所を残したい
- 日々行ったことを記録したい
- 旅行や趣味の活動を収集したい
- 自分で決めた目標の進捗を楽しみたい
- 過去の行動を後から振り返りたい

## 1.4 プロダクト原則

本プロダクトでは、以下を優先する。

**押すことが簡単であること**

詳細な情報入力を要求せず、体験したその場で短時間でスタンプを押せることを優先する。

**ラリーが記録の起点であること**

スタンプは必ずラリーに押す。テーマとタイプはラリーを作る時点で決まる。押す操作はタイプで変わらず、ワンタップで日時を残す。補足（メモなど）は任意で、位置情報は取れたときだけ足せる。

**ユーザー自身が意味を決められること**

「何を記録するか」「どのようにまとめるか」「何を達成とするか」をアプリ側で過度に制約しない。

**振り返ることが楽しいこと**

単なるデータの保存ではなく、時間の経過とともに自分の行動や経験が蓄積されていく感覚を提供する。

# 2. 基盤

## 2.1 アプリケーション基盤

モバイルアプリとして提供する。

初期開発では以下を前提とする。

- React Nativeを利用する
- iOS / Androidでの利用を想定する
- ユーザーログインを必須としない
- 個人利用を基本とする

## 2.2 ナビゲーション

アプリの主要なナビゲーションは以下の3領域とする。

### ホーム

ラリーを起点にスタンプを押すための領域。

主に以下の操作を提供する。

- 自分のラリー一覧を見る
- ラリーを作る
- ラリーを選んでスタンプを押す
- 押したスタンプをそのラリーの直下で確認する

### 記録

押したスタンプとラリーを確認・整理する領域。

主に以下を扱う。

- ラリー詳細（押したスタンプの一覧・収集数・進捗）
- スタンプ詳細
- ラリー横断の時系列一覧
- ラリー・スタンプの編集

UI上の名称は開発過程で変更可能とする。画面の配置・遷移の詳細は [design.md](./design.md) を正とする。

### カレンダー

記録を時間軸で振り返るための領域。

日付ごとに押したスタンプを確認できることを目的とする。

## 2.3 基本概念

### ラリー

ユーザー自身が設定したテーマに沿ってスタンプを集める台紙を表す。名称と、集めるスタンプのタイプを持つ。目標数は任意で設定できる。

タイプは以下の3種類である。

**人**

「誰に会ったか」を集める。

例：

- 今年会った研究者
- 同期の仲間

**場所**

「どこに行ったか」を集める。

例：

- 東京の美術館
- 京都旅行
- 山手線全駅

**行動**

「何をしたか」を集める。

例：

- 今年やりたいこと
- 週末のランニング

### スタンプ

ラリーに押した1回の体験を表す。スタンプは必ず1つのラリーに属し、記録の本体は押した日時である。タイプ（人 / 場所 / 行動）によって入力項目やデータ形は変わらない。

押した直後に、操作を止めないトーストで任意にメモを足せる。位置情報は取れたときだけ付与し、取れなくてもスタンプは押せる。写真等の証跡は必要になってから扱う。

## 2.4 プライバシー原則

本アプリでは人や位置に関する情報を扱う可能性があるため、個人の記録が意図せず他者へ公開されないことを基本とする。

初期段階では、他ユーザーへの公開・SNS的な共有・ランキング等を必須要件としない。
