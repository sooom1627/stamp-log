# Brand

アプリの名前・約束・見た目・言葉づかい・掲載の方針。プロダクトの定義は [product.md](./product.md)、画面は [design.md](./design.md) を参照する。検討の経緯とモックは [Ato ブランド計画](https://claude.ai/artifact/XJXy2G5SfUhThu5h2Pz5yN)、機能の案は [Ato 機能計画](https://claude.ai/artifact/EX65vNhgjqB1ado13tBNyS) にある（どちらもオーナーのみ閲覧可）。

# 1. 名前と約束

## 1.1 名前

- アプリ名は **Ato**（あと／跡）。振り返ると残っている跡を指す。英語圏では意味を持たない短い語として使う
- ホーム画面のアイコンの下には「Ato」とだけ出す（`app.json` の `expo.name`）。`slug` と `bundleIdentifier` は変えない
- App Store の名前には副題を付ける。オーストラリアの国税庁（ATO）の公式アプリがあり、「ato」の検索で並ぶため

## 1.2 約束（キャッチコピー）

| 言語   | コピー                     |
| ------ | -------------------------- |
| 日本語 | 振り返れば、残ってる。     |
| 英語   | Look back. It's all there. |

アプリ内の文言、掲載画像、発信は、この一文に反していないかで決める。

## 1.3 誰のためか

- 主: 日記や習慣アプリを入れては、続かずにやめてきた人。途切れた記録を見て落ち込みたくない
- 副: すでに何かを集めている人（カフェ、サウナ、ライブ、旅先、会った人）。「何回行ったっけ」を数えたい
- 両者が欲しいのは「記録をつけること」ではなく、振り返ったときに残っていること
- これは仮説で、TestFlight で確かめる

# 2. 言葉づかい

## 2.1 トーン

静か、責めない、余白がある。押していない日は「抜け」ではなく、ただの余白として扱う。

## 2.2 使う言葉・使わない言葉

| 使う                         | 使わない                       |
| ---------------------------- | ------------------------------ |
| 残る、集まる、振り返る、押す | 続ける、達成、目標、記録を守る |
| N stamps（押した数）         | 連続日数、残り回数、達成率     |
| 日付（Oct 18）               | 空いた日数（7 days ago）       |

- 連続日数や「押していない日」は見せない（[screens/home.md](./screens/home.md) と同じ方針）
- 通知で開かせない。振り返りのきっかけは、アプリを開いたときだけ出す

# 3. 見た目

## 3.1 ロゴ

- アイコンは **Q8-b**（白地に、少し下げたオレンジの太陽と、-14° 傾いた 3 本の切れ込み、その下のネイビーの帯）。仕様は S-049（#162）
- ワードマーク（マーク + 文字）は未決。L4 / L7 / L8 から選ぶ（#162）

## 3.2 色

アプリの `tailwind.css` のトークンと同じ。

| 役割                   | 値                                            |
| ---------------------- | --------------------------------------------- |
| アクセント（太陽）     | `#fdba74` → `#f97316`                         |
| 帯・文字（ネイビー）   | `#334155` → `#1e293b`                         |
| 淡い面                 | `#fff7ed`（accent-subtle）                    |
| 濃い文字のアクセント   | `#9a3412`（accent-strong）                    |
| ホームの背景（ライト） | `#ece5d6` → `#efede8` → `#ebebea`（上から下） |
| ホームの背景（ダーク） | `#1a1814` → `#121212` → `#141414`（上から下） |

- オレンジは「今」を表す印にだけ使う。ホームでは今日の判子の輪だけ。押した印や 7 日のドットはネイビーと文字色で表す

# 4. App Store の掲載

## 4.1 名前と副題

上限はそれぞれ 30 文字。

| ローカライズ | 名前                     | 副題                       |
| ------------ | ------------------------ | -------------------------- |
| 日本語       | Ato - 振り返るスタンプ帳 | 振り返れば、残ってる       |
| 英語         | Ato: Stamp your days     | Look back. It's all there. |

名前が登録できるかは、App Store Connect で作るまで確定しない。

## 4.2 スクリーンショット

iPhone 用を 6 枚。画面は実機で撮り、見出しと補足を上に重ねる。

| #   | 日本語                       | 英語                           | 画面                         |
| --- | ---------------------------- | ------------------------------ | ---------------------------- |
| 1   | 振り返れば、残ってる。       | Look back. It's all there.     | ホーム                       |
| 2   | 集めたいものは、自分で決める | You choose what to collect     | ラリーを作る                 |
| 3   | 押すのは、ワンタップだけ     | One tap. That's it.            | ホームと押した直後のトースト |
| 4   | 気づけば、こんなに集まってる | Look how much you've collected | ラリー詳細                   |
| 5   | あの日に、すぐ戻れる         | Back to any day                | Logs                         |

- 日本語版は E-007（多言語対応）の後に撮る

## 4.3 キーワードと説明文

キーワード（100 文字まで）は仕様から拾った初稿で、検索量は調べていない。

- 日本語: スタンプ,ラリー,記録,ライフログ,振り返り,カレンダー,旅行,出会い,コレクション,スタンプ帳
- 英語: stamp,collect,log,lifelog,tracker,calendar,travel,journal,memories,passport

説明文の冒頭:

- 日本語: 会った人、行った場所、やったこと。そのときワンタップで押すだけ。続けなくていい。振り返れば、ちゃんと残っています。
- 英語: People you met, places you went, things you did. Stamp it with one tap. No streaks to keep. Look back, and it's all there.

# 5. 課金の方針

- 公開時は無料だけで出す
- 押す・振り返る・引き継ぐ（ラリーとスタンプの数、過去のスタンプ、Logs、写真、書き出し・読み込み）は無料のまま。上限は付けない
- 有料にするのは「残ったものをもっと楽しむ」部分だけで、買い切りの「Ato+」を想定する。中身と価格は未定
- アプリ内の機能を売るときは App 内課金を使う（App Review Guidelines 3.1.1）
