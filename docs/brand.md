# Brand

アプリの名前・約束・見た目・言葉づかい・掲載の方針。プロダクトの定義は [product.md](./product.md)、画面は [ia.md](./ia.md) を参照する。検討の経緯とモックは [Ato ブランド計画](https://claude.ai/artifact/XJXy2G5SfUhThu5h2Pz5yN)、機能の案は [Ato 機能計画](https://claude.ai/artifact/EX65vNhgjqB1ado13tBNyS) にある（どちらもオーナーのみ閲覧可）。

# 1. 名前と約束

## 1.1 名前

- アプリ名は **Ato**（あと／跡）。振り返ると残っている跡を指す。英語圏では意味を持たない短い語として使う
- ホーム画面のアイコンの下には「Ato」とだけ出す（`app.json` の `expo.name`）。`slug` と `bundleIdentifier` は変えない
- App Store の名前には副題を付ける。オーストラリアの国税庁（ATO）の公式アプリがあり、「ato」の検索で並ぶため

## 1.2 約束（キャッチコピー）

| 言語   | コピー                           |
| ------ | -------------------------------- |
| 日本語 | 振り返ると、ちゃんと残っている。 |
| 英語   | Look back. It's all there.       |

アプリ内の文言、掲載画像、発信は、この一文に反していないかで決める。

## 1.3 誰のためか

### 1.3.1 仕組みから決まる得意・不得意

Ato の仕組みは「テーマ（ラリー）を決めて、起きたときにワンタップで日時を残す」だけ。ここから、誰に向くかが決まる。

| 仕組み                                                     | 得意なこと                                         |
| ---------------------------------------------------------- | -------------------------------------------------- |
| 押すのは起きたときだけ。毎日の目標や頻度は持たない         | 不定期なできごとを残す。間があいても失敗にならない |
| 記録の本体は日時。ラリーごとに数が集まる                   | 「何回目？」「いつだっけ？」に答える               |
| 押すのはワンタップ。メモと写真は任意で、あとから付けられる | 書くのが面倒で日記が続かなかった人でも残せる       |
| カレンダーに絵文字、ラリーに押した数だけの点               | 振り返ったときに「こんなに残っている」と見える     |
| ログイン不要、記録は端末の中だけ                           | 人に見せたくないこと（会った人、体のこと）も残せる |

次の人は狙わない。仕組みが合わないため。

| 仕組み                                 | 向かない人                                   |
| -------------------------------------- | -------------------------------------------- |
| 量を持たない（時間、距離、金額、体重） | 数値を記録して伸びを見たい人                 |
| 通知で呼ばない（2.2）                  | 毎日リマインドされないと続かない人           |
| 投稿は短いメモと写真                   | 長い日記を書きたい人                         |
| 個人利用。共有は画像だけ（3.3）        | 友だちと記録を見せ合ったり、競ったりしたい人 |

### 1.3.2 3 つの使い方

使う人は、残したいものによって 3 つに分かれる。サイト（ato-app.pages.dev）と App Store の掲載では、この 3 つを同じ重さで見せる。

| 使い方           | 欲しいもの                         | 例                                                                 | Ato での答え                                                                                     |
| ---------------- | ---------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| がんばったこと   | やった日が、責められずに残ること   | 資格・語学の勉強、ジム、ランニング、自炊                           | やらなかった日は数えない。間があいても、また押せばいい。ラリーを開くと、週に何回できたかがわかる |
| 好きなこと       | 何回目か、どこへ行ったかが残ること | 推し活（ライブ、舞台、遠征）、サウナ、カフェ、ラーメン、映画館、山 | ラリーごとの数と最初の日。写真を添えて残せる。月やラリーを画像にして共有できる                   |
| 忘れたくないこと | 「いつだっけ」に答えられること     | 仕事で会った人、子どもとのおでかけ、旅先                           | 日時が必ず残る。メモで何を話したかを添えられる。記録のアルバムで写真を見返せる                   |

- がんばったこと: 日記や習慣アプリを入れては、続かずにやめてきた人。途切れた記録を見て落ち込みたくない。続けることを求めないのが、ほかの習慣アプリとの違い
- 好きなこと: すでに何かを集めている人。メモアプリや SNS の投稿で数えている人が多いと考える。共有の画像（3.3）はここに効く
- 忘れたくないこと: 日時と短いメモがあれば足りる人。記録が端末の中だけにあることが効く
- 3 つに共通して欲しいのは「記録をつけること」ではなく、振り返ったときに残っていること

### 1.3.3 確かめること

3 つの使い方はどれも仮説で、どの使い方の人が多いか、続けて開くかの数字はまだない。アクセス解析は入れない方針（プライバシーポリシー）なので、TestFlight の参加者に聞いて確かめる。

- 最初に作るラリーが、3 つのどれに多いか
- 2 週間後も押しているのは、どの使い方の人か
- 好きなことの人が、共有の画像を使うか

# 2. 言葉づかい

## 2.1 トーン

静か、責めない、余白がある。押していない日は「抜け」ではなく、ただの余白として扱う。

## 2.2 使う言葉・使わない言葉

| 使う                         | 使わない                       |
| ---------------------------- | ------------------------------ |
| 残る、集まる、振り返る、押す | 続ける、達成、目標、記録を守る |
| N stamps（押した数）         | 連続日数、残り回数、達成率     |
| 日付（Oct 18）               | 空いた日数（7 days ago）       |

- 連続日数や「押していない日」は見せない（[screens/home.md](./screens/home.md) と同じ方針）
- 通知で開かせない。振り返りのきっかけは、アプリを開いたときだけ出す

## 2.3 日本語の用語と文体

アプリ内の日本語は、Apple の日本語 UI のように、何ができるかを短く事実で書く。比喩や余韻のある言い回しは、キャッチコピー（1.2）以外では使わない。

- 見出しとボタンは体言止めか短い言い切り。説明・エラー・確認は です・ます
- iOS の標準の言い方に合わせる。例: `キャンセル` / `削除` / `完了` / `再試行` / `エラーが起きました` / `この操作は取り消せません。`
- 英語のまま出すもの（アプリ名、`Your Days`、日付、数の表記など）は [ia.md](./ia.md)「言語」に従う

| 英語            | 日本語          |
| --------------- | --------------- |
| Rally           | ラリー          |
| Stamp（名詞）   | スタンプ        |
| stamp（動詞）   | 押す / 記録する |
| Logs            | 記録            |
| Home / Settings | ホーム / 設定   |
| Favorites       | お気に入り      |
| Archive         | アーカイブ      |
| Memo / Photos   | メモ / 写真     |
| Album           | アルバム        |

# 3. 見た目

## 3.1 ロゴ

- アイコンは **Q8-b**（白地に、少し下げたオレンジの太陽と、-14° 傾いた 3 本の切れ込み、その下のネイビーの帯）。仕様は S-049（#162）
- ワードマーク（マーク + 文字）は未決。L4 / L7 / L8 から選ぶ（#162）

## 3.2 色・文字・余白・角丸

アプリの中の色・文字・余白・角丸・アイコンの大きさは [DESIGN.md](../DESIGN.md) が正。値は `tailwind.css` のトークンと同じ。ロゴと App Store の掲載物は次の色を使う。

| 役割                 | 値                    |
| -------------------- | --------------------- |
| アクセント（太陽）   | `#fdba74` → `#f97316` |
| 帯・文字（ネイビー） | `#334155` → `#1e293b` |

- オレンジは「今」を表す印にだけ使う（使う場所は DESIGN.md の Colors）

## 3.3 共有の見た目

共有する画像・共有のシート・入り口は、アプリの今の色と部品だけで作る。新しい色や書体は足さない。画像の形と寸法は [DESIGN.md](../DESIGN.md) の Components「共有の画像」。

| 要素     | アプリでの出どころ                                                   | 共有での使い方                                                                                     |
| -------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 背景     | タブの画面のグラデーション（`canvas-top` → `canvas-bottom`）         | 画像の地                                                                                           |
| 面       | ホームのカード（`surface`、`rounded-card`、影なし）                  | 画像の中身は白いカード 1 枚                                                                        |
| 押した印 | タイルの 7 日の点（`foreground`）                                    | ラリーの丸、月のマス、ホームの先月のカード。すべてネイビー                                         |
| 今の印   | 今日の判子の輪、タイルの押した印（`accent`）                         | いちばん新しいスタンプ 1 つだけ                                                                    |
| 文字     | システムの書体。数は太字。カードの頭は「小さな丸 + 言葉 + 右に補足」 | 画像の頭もカードの頭と同じ形。大きな数は太字                                                       |
| マーク   | ヘッダーの Ato のマーク（タイル無し）                                | 画像の下に「マーク + `Ato`」、右にコピー `Look back. It's all there.`（1.2）。日本語でも英語のまま |

- 画像に入れないもの: メモ・写真・押した時刻・連続日数・達成率・前の期間との比較（2.2）
- 押していない日は画像でも目立たせない。ラリーの画像は押した数だけ丸を並べ、日付には並べない（空いた日が見えないように）
- 下のマークはワードマーク（3.1、#162）が決まるまで、ヘッダーのマークと `Ato` の文字で仮に組む

## 4.3 キーワードと説明文

キーワード（100 文字まで）は仕様から拾った初稿で、検索量は調べていない。

- 日本語: スタンプ,ラリー,記録,ライフログ,振り返り,カレンダー,旅行,出会い,コレクション,スタンプ帳
- 英語: stamp,collect,log,lifelog,tracker,calendar,travel,journal,memories,passport

説明文の冒頭:

- 日本語: 会った人、行った場所、やったこと。そのときワンタップで押すだけ。続けなくていい。振り返れば、ちゃんと残っています。

# 5. 課金の方針

- 公開時は無料だけで出す
- 押す・振り返る・引き継ぐ（ラリーとスタンプの数、過去のスタンプ、Logs、写真、書き出し・読み込み）は無料のまま。上限は付けない
- 有料にするのは「残ったものをもっと楽しむ」部分だけで、買い切りの「Ato+」を想定する。中身と価格は未定
- アプリ内の機能を売るときは App 内課金を使う（App Review Guidelines 3.1.1）
