# メモを追加

## 目的 / 対応 Story

押した直後だけ、任意でスタンプにメモを足す。操作は止まらない。トーストが消えたらメモなしのまま残る。

- S-002 ラリーにスタンプを押す

## 入りと出

- 入り: スタンプ押下後のトースト「メモを追加」。ルート案 `/add-stamp-memo?stampId=`（formSheet）
- 出: 保存成功で閉じ、ホームに戻る。シートを下ろしてもスタンプは残り、メモは付かない

## レイアウト

現状と目標は同じでよい。押下フローは変えない。

```
メモを追加

[ メモを入力                    ]

            [ 保存 ]
```

- 空（空白のみ）では保存できない（現状どおり）
- 後からのメモ編集は E-005。この画面は押下直後のみ
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: メモ文字列
- 保存後: ホーム直下とラリー詳細・スタンプ詳細にメモが見える

## 空 / 読込 / エラー

- 空: プレースホルダのみ
- 読込: stampId 不正なら保存できない。専用エラー画面は作らない
- エラー: mutation 失敗はトースト
