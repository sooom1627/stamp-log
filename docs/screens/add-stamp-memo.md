# メモと写真を追加

## 目的 / 対応 Story

押した直後だけ、任意でスタンプにメモと写真を足す。操作は止まらない。トーストが消えたらメモも写真もないまま残る。

- S-002 ラリーにスタンプを押す
- S-035 スタンプを押すときに写真を最大 4 枚付けられる

## 入りと出

- 入り: スタンプ押下後のトースト。文言は `Add a memo or photos?`、ボタンは `Add`。ルート案 `/add-stamp-memo?stampId=`（formSheet）
- 出: 保存成功で閉じ、ホームに戻る。シートを下ろしてもスタンプは残り、メモも写真も付かない
- 写真ライブラリ: `Add` から開くシステムの写真選択（複数選択）。閉じるとこのシートに戻る

## レイアウト

```
            ───                 ← グラバー（ネイティブのヘッダーは出さない）
🗼 今年会った研究者             ← 補足行（小。スタンプのラリー）
Memo & photos                   ← 見出し（大）

Memo
[ Enter memo                    ]

Photos                     1 / 4  ← 選んだ枚数 / 上限
┌────┐ ┌ ─ ─┐
│ 🖼 ×│ │ +  │                    ← 選んだ写真（× で外す）と Add。4 列に並べる
└────┘ └ ─ ─┘
Save with a memo, photos, or both

            [ Save ]
```

- 写真は写真ライブラリからだけ選ぶ。1 回の選択で残りの枚数まで選べる。選んだ順に並べる
- 4 枚選んでいるときは Add を出さない
- 選んだ写真の右上の × で外す（読み上げは `Remove photo 1` のように何枚目かを含める）。Add の読み上げは `Add photos`
- 保存はメモ（前後の空白を除く）か写真 1 枚以上があれば押せる。どちらも無ければ押せない
- 写真はアプリに保存するときに撮影位置などの EXIF を除く。写真ライブラリの元の写真は変えない
- 保存するときに、一覧用の小さい画像（短い辺 400px。元が小さければ縮めない）も作る。Album のマスはこれを出し、全画面では元の大きさの写真を出す
- この画面は押下直後のメモと写真の追加だけを扱う。後からのメモ編集は [edit-stamp.md](./edit-stamp.md) で行う
- シートは入力欄・写真欄と保存ボタンを含む内容の高さに合わせる
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: メモ文字列、写真（0〜4 枚）
- 保存後: ラリー詳細と Logs の投稿にメモと写真のマーク（写真アイコンと枚数）が見える

## 空 / 読込 / エラー

- 空: メモはプレースホルダのみ。写真は `0 / 4` と Add だけ
- 読込: `stampId` が不正、またはそのスタンプが存在しないならシートを閉じる。専用エラー画面は作らない
- エラー: mutation 失敗はトースト。メモも写真も保存されない
