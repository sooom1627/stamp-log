# スタンプ詳細

## 目的 / 対応 Story

押した 1 件を改めて見る。日時、メモ、属しているラリーが分かればよい。

- S-007 スタンプの詳細を見る

受け入れの「誰 / どこ / 何」はスタンプの別フィールドではない。ラリーのタイプと名称で示す。

## 入りと出

- 入り:
  - ホーム直下のスタンプ行
  - ラリー詳細のスタンプ行
  - （E-004）記録タイムライン / 日詳細
- ルート案 `/stamps/[id]`
- 出: 戻る。ラリー名タップで [rally-detail.md](./rally-detail.md) へ進めてよい

## レイアウト

```
‹ 戻る

9月20日 11:40

ラリー
今年会った研究者          人

メモ
研究室で話した
```

- メモが無ければメモ欄は出さない（「なし」と書かない）
- 編集・削除・移動は E-005。置かない

## 出すデータ

- 押した日時
- 所属ラリーの名称とタイプ
- メモ（あれば）

## 空 / 読込 / エラー

- 空: 1 件画面なのでリスト空はない
- 読込: 出るまで待つ
- エラー: 読めない / 無いときはメッセージ。戻るで足りる
