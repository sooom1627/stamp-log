# 年のまとめ

## 目的 / 対応 Story

年末に、その年のラリーとスタンプのまとめを数枚のページで見て、各ページを画像で共有する。

- S-058 記録を画像にして SNS に送る（「Ato の 1 年」）

## 入りと出

- 入り: [records-timeline.md](./records-timeline.md) の年の入り口（その年にスタンプがあり、年末の決まった期間だけ）。ルート `/year-review?year=2026`（全画面モーダル）
- 出:
  - 閉じるボタン → Logs（全画面モーダルには下スワイプで閉じる操作が無い。[stamp-photos.md](./stamp-photos.md) と同じ）
  - 各ページの `Share` → [share-image.md](./share-image.md)（formSheet。`/share-year?year=&page=`）
- `year` が不正（数でない・今年より先）なら閉じる

## レイアウト

```
                               ✕    ← 閉じるボタン
┌──────────────────────────────┐
│                              │
│   （ページ。共有の画像と同じ枠） │    ← 横にめくる
│                              │
└──────────────────────────────┘
            ●  ·  ·                  ← 今の位置
[        ⇪  Share                 ]  ← そのページを共有
```

- 全画面モーダルにする（写真の全画面と同じ。横にめくる画面のため）。タブバーは出さない
- 各ページは共有の画像（[share-image.md](./share-image.md)）と同じ枠で描き、見えているものがそのまま画像になる
- 中身は、その年のスタンプの数、ラリーごとの数、その年の最初と最後のスタンプ
- 出さないもの: 前の年との比較、達成率、連続日数、押していない日の数

## 出すデータ

- その年のスタンプの数、ラリーごとの数（ラリーの絵文字と名称）、その年の最初と最後のスタンプの日付とラリー

## 空 / 読込 / エラー

- 空: スタンプが 0 の年には入り口が出ないので開かない
- 読込: 出るまで待つ
- エラー: 読めないときはメッセージ + 再試行
