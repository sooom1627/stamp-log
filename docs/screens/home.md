# ホーム

## 目的 / 対応 Story

スタンプを押す起点。ラリーを 2 列のタイルで並べ、タイルからワンタップで押す。上部の今日のカードで、今日押したラリーを眺められる。続けることを促す表示（残り件数、連続日数）は出さない。全件はラリー詳細。

- S-001 ラリーを作成する
- S-002 ラリーにスタンプを押す
- S-023 ラリーに絵文字を付ける
- S-008 ラリーの収集数を見る
- S-029 ホームを、今日の判子のカードと 2 列タイルにする

## 入りと出

- 入り: タブ「ホーム」。ルート案 `/`
- 出:
  - 一覧の最後の `New rally` タイル → [create-rally.md](./create-rally.md)
  - タイル右上のボタン → その場でスタンプが付く。トーストから [add-stamp-memo.md](./add-stamp-memo.md)
  - タイルの名称部分のタップ → [rally-detail.md](./rally-detail.md)
  - `View All` → ラリー一覧
- 今日のカードはタップしても遷移しない
- ラリーの削除はホームに置かない。[rally-detail.md](./rally-detail.md) で確認ダイアログ付きで行う

```

│  │🏃📚│  Morning run · Reading    │     左に今日の絵文字を重ねた判子
│  ╰────╯  （名前は 2 行まで）      │     右に今日押したラリーの名前
└─────────────────────────────────┘

Your Days                  View All

┌──────────────┐ ┌──────────────┐
│ [🗼]     (＋) │ │ [😀]     (✓) │  ← 右上のボタンで今日押す
│ Tokyo towers  │ │ Researchers  │
│ 10 stamps     │ │ 8 stamps     │
│ Mo Tu We Th Fr Sa Su │ │ Mo Tu … Su │
│ ·  ·  ·  ·  ●  ·  · │ │ ·  ● … ●  │  ← 直近7日のドット（右端が今日）
└──────────────┘ └──────────────┘

│（同様に次のラリー）│ │ ┌ ─ ─ ─ ─ ┐ │

└──────────────┘ └──────────────┘

```

### 見出し

- 大見出しは今日の月日（`September 20`）、その下に曜日（`Sunday`）。挨拶は出さない（[design.md](../design.md) のタブルート共通の見出し）

### 今日のカード

- 今日押したスタンプだけを出す。直近の日々の振り返りはタイルの 7 日ドットとラリー詳細に任せる
- 左に今日の判子（88px）。今日押したラリーの絵文字を、最初に押した順に少しずつ重ね、1 つずつ傾けて押したように入れる。1 つなら大きく 1 つ、2〜3 つは 1 列、4〜5 つは上に 3 つ・下に 2 つの 2 段、6 つ以上は 4 つと `+N`。アクセント色の細い輪 1 本で、日付から決まる角度で少し傾ける
- 右に件数（`2 stamps today`）と、今日押したラリーの名前を `·` でつないだ文字。並びは最初に押した順。同じラリーを今日複数回押しても名前は 1 つ。名前は 2 行まで出し、あふれた分は省略する。カードの高さは判子の高さ（104px）で固定し、ラリーが多くても伸びない。読み上げには全部のラリーを入れる
- 件数は今日押したラリーの数。同じラリーを今日複数回押しても 1 と数える（以前の帯の判子と同じ数え方）
- 今日まだ何も押していないときは、判子を薄い灰色の破線の輪にして月と日（`SEP` / `20`）を入れ、`No stamps yet today` と `What you stamp today shows up here.` を出す。タイルから押すとそのラリーが判子と名前に加わる
- 色は控えめにする。背景は薄いオレンジ（`accent-subtle`）で下のタイルと分ける。アクセント色は判子の輪だけ。累計スタンプ数、人 / 場所 / 行動の構成比、今月の件数は出さない

### ラリーのタイル

- ラリーを 2 列のタイルで並べる。並びは収集数の多い順で、同数なら新しく作ったラリーが先。ホームを開いている間は並びを変えず、押したタイルがその場に残る。ほかの画面から戻ったときに並べ直す
- 一覧の上に英語のセクション見出し `Your Days` と `View All` を置く。内部用語の「ラリー」は出さない
- タイルの左上に作成時に選んだ絵文字、その下に名称（2 行まで）と収集数。タイプ名とタイプアイコンは表示しない
- 絵文字が保存されていない既存ラリーには、タイプの初期絵文字（人: 😀 / 場所: 🏠 / 行動: 👏）を表示する
- タイル右上のボタンで今日のスタンプを押す。未記録はオレンジのリングに `＋`、記録済みはオレンジの塗りにチェックで、押せなくする
- 名称部分のタップは詳細。今日のスタンプ操作は名称のタップと分けて取る
- タイルの下に、今日を含む直近 7 日を 2 文字の曜日（`Mo Tu We Th Fr Sa Su`）とドットで、古い日から今日へ並べる（右端が今日）。今日の曜日だけ通常の文字色の太字。0 件は小さい薄色のドット、1 件以上はオレンジのドット。同日回数による濃淡や数字は出さない。今日もドットで表し、押す操作は右上のボタンだけ
- 1 日 1 回の制限はホーム UI だけに適用する。DB 制約や保存処理、既存の同日重複データは変えない
- 一覧の最後に `New rally` タイル（破線の枠、`＋` と `New rally`）を置き、ラリー作成を開く。画面に浮かぶ作成ボタンは置かない

## 出すデータ

- ラリー: 名称、絵文字。タイプ（人 / 場所 / 行動）はホームでは使わない
- 収集数。目標があるときだけ `現在 / 目標`
- 今日のスタンプ（今日のカード）と、直近 7 日分のスタンプ日時（タイルでは日ごとの記録有無だけを表示）

## 空 / 読込 / エラー

- 空: ラリーが無い。`New rally` タイルだけ見える（`Your Days` と `View All` は出さない）。今日のカードは押していないときの表示になる
- 読込: 一覧が出るまで待つ。スケルトンは必須にしない
- エラー: 「読み込めませんでした」+ 再試行（現状どおり）
