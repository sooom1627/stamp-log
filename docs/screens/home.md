# ホーム

## 目的 / 対応 Story

スタンプを押す起点。ラリーを一覧し、作成し、ワンタップで押す。ホーム上部でコレクション全体、各ラリーで直近の活動日を見渡す。全件はラリー詳細。

- S-001 ラリーを作成する
- S-002 ラリーにスタンプを押す
- S-023 ラリーに絵文字を付ける
- S-008 ラリーの収集数を見る

## 入りと出

- 入り: タブ「ホーム」。ルート案 `/`
- 出:
  - 「ラリーを作る」→ [create-rally.md](./create-rally.md)
  - 「スタンプを押す」→ その場で付く。トーストから [add-stamp-memo.md](./add-stamp-memo.md)
  - ラリー行タップ → [rally-detail.md](./rally-detail.md)
  - 直下のスタンプ行タップ → [stamp-detail.md](./stamp-detail.md)
- 削除: 確認ダイアログのまま（S-001）。ラリー行の中。

## レイアウト

現状: 中央寄せ。ラリー名、タイプ、「スタンプを押す」、直下に全スタンプ（日時 + メモ）、削除。収集数なし。詳細へ進めない。

目標:

```
ホーム                         [ラリーを作る]

┌─────────────────────────────────┐
│ 38 STAMPS              今月 +12 │
│                                 │
│ ████████ ███████████ █████      │  ← 人 / 場所 / 行動の構成比
│   人 12      場所 18     行動 8 │  ← 実装はアイコン + 数字
└─────────────────────────────────┘

Your Days

┌─────────────────────────────────┐
│ [😀] 今年会った研究者       [削除] │
│      スタンプ 12個              │
│ Mon Tue Wed Thu Fri Sat Sun     │
│  ·   ●   ·   ·   ●   ●  [＋]  │  ← 今日からスタンプ
└─────────────────────────────────┘

（同様に次のラリー）

[ ホーム ] [ 記録 ] [ カレンダー ]
```

- ラリー行本体のタップは詳細。今日のスタンプ操作 / 削除は行タップと分けて取る。
- 名称左には作成時に選んだ絵文字を表示し、タイプ名とタイプアイコンは表示しない。収集数は名称の直下に置く。
- 絵文字が保存されていない既存ラリーには、タイプの初期絵文字（人: 😀 / 場所: 🏠 / 行動: 👏）を表示する。
- 一覧の上に英語のセクション見出し `Your Days` を置く。内部用語の「ラリー」は出さない。
- ホーム上部は全ラリーを横断し、累計スタンプ数、今月の件数、人 / 場所 / 行動の構成比を示す。
- 構成比バーはオレンジ、ネイビー、スレートで分ける。0件時は淡色の一本と各タイプ0件を示す。
- 今日を含む直近7日を、英語3文字の曜日と丸だけで古い日から今日へ並べる。
- 活動表示はラリー行の横幅いっぱいを使い、背景、`Last 7 days`、シェブロン、アコーディオンは出さない。
- 0件は小さい薄色の丸、1件以上はオレンジの丸。同日回数による濃淡や数字は出さない。
- 今日が未記録なら右端のリング内に `＋` を出し、タップでスタンプを押す。記録済みならオレンジの丸に変えて押せなくする。
- 1日1回の制限はホームUIだけに適用する。DB制約や保存処理、既存の同日重複データは変えない。
- これは表示デザインだけの変更とし、スタンプの保存、メモ、Query、DB、画面遷移は変えない。

### 活動表示（S-022 T-002）

- 比較案 C（todayRing）を採用する。
- 曜日と丸は名称列への inset にせず、ラリー行のコンテンツ幅いっぱいに均等配置する。
- 比較用の A / B / C 切替は出さない。

## 出すデータ

- ラリー: 名称、絵文字。タイプ（人 / 場所 / 行動）は行には出さず、サマリー集計に使う
- 収集数。目標があるときだけ `現在 / 目標`
- 全スタンプの累計、今月の件数、ラリータイプ別件数
- 直近7日分のスタンプ日時（ホームでは日ごとの記録有無だけを表示）

## 空 / 読込 / エラー

- 空: ラリーが無い。「ラリーを作る」だけ見える
- 読込: 一覧が出るまで待つ。スケルトンは必須にしない
- エラー: 「読み込めませんでした」+ 再試行（現状どおり）

## 対象外

- 日ごとの回数、日時、メモの表示
- 目標達成時の見た目（必要になったら rally-detail 側で扱う）
