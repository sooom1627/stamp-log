# ホーム

## 目的 / 対応 Story

スタンプを押す起点。ラリーを 2 列のタイルで並べ、タイルからワンタップで押す。上部の判子の帯で、直近 7 日に押した日とその日に押したラリーを眺められる。続けることを促す表示（押していない日、残り件数、連続日数）は出さない。全件はラリー詳細。

- S-001 ラリーを作成する
- S-002 ラリーにスタンプを押す
- S-023 ラリーに絵文字を付ける
- S-008 ラリーの収集数を見る
- S-029 ホームを、押した日の判子の帯と 2 列タイルにする

## 入りと出

- 入り: タブ「ホーム」。ルート案 `/`
- 出:
  - 一覧の最後の `New rally` タイル → [create-rally.md](./create-rally.md)
  - タイル右上のボタン → その場でスタンプが付く。トーストから [add-stamp-memo.md](./add-stamp-memo.md)
  - タイルの名称部分のタップ → [rally-detail.md](./rally-detail.md)
  - `View All` → ラリー一覧
- 判子の帯の判子はタップしても遷移しない
- ラリーの削除はホームに置かない。[rally-detail.md](./rally-detail.md) で確認ダイアログ付きで行う

### 判子の帯

- 今日を含む直近 7 日のうち、スタンプを押した日だけを判子として並べる。押していない日は出さない
- 右端が今日で、左へ新しい順に遡る。横スクロールで、開いたときは右端（今日）が見える
- 判子にはその日に押したラリーの絵文字を入れる。同じ日に複数のラリーを押した日は絵文字を重ねる（最大 3 つ）。同じラリーを同じ日に複数回押しても絵文字は 1 つ
- 判子の下に曜日と日（`Sat 19`）、今日は `Today`
- 今日まだ何も押していないときは、右端にインクなしの今日の判子（破線の輪と月・日）を置く。押すとそのラリーの絵文字が入る
- 判子は日ごとに決まった角度で少し傾ける
- 帯の見出しは左に `Last 7 days`、右に累計スタンプ数だけ。人 / 場所 / 行動の構成比、今月の件数は出さない

### ラリーのタイル

- ラリーを 2 列のタイルで並べる。一覧の上に英語のセクション見出し `Your Days` と `View All` を置く。内部用語の「ラリー」は出さない
- タイルの左上に作成時に選んだ絵文字、その下に名称（2 行まで）と収集数。タイプ名とタイプアイコンは表示しない
- 絵文字が保存されていない既存ラリーには、タイプの初期絵文字（人: 😀 / 場所: 🏠 / 行動: 👏）を表示する
- タイル右上のボタンで今日のスタンプを押す。未記録はオレンジのリングに `＋`、記録済みはオレンジの塗りにチェックで、押せなくする
- 名称部分のタップは詳細。今日のスタンプ操作は名称のタップと分けて取る
- タイルの下に、今日を含む直近 7 日を 1 文字の曜日（`M T W T F S S`）とドットで古い日から今日へ並べる。0 件は小さい薄色のドット、1 件以上はオレンジのドット。同日回数による濃淡や数字は出さない。今日もドットで表し、押す操作は右上のボタンだけ
- 1 日 1 回の制限はホーム UI だけに適用する。DB 制約や保存処理、既存の同日重複データは変えない
- 一覧の最後に `New rally` タイル（破線の枠、`＋` と `New rally`）を置き、ラリー作成を開く。画面に浮かぶ作成ボタンは置かない

## 出すデータ

- ラリー: 名称、絵文字。タイプ（人 / 場所 / 行動）はホームでは使わない
- 収集数。目標があるときだけ `現在 / 目標`
- 全スタンプの累計
- 直近 7 日分のスタンプ日時（判子の帯では日ごとに押したラリー、タイルでは日ごとの記録有無だけを表示）

## 空 / 読込 / エラー

- 空: ラリーが無い。`New rally` タイルだけ見える（`Your Days` と `View All` は出さない）。直近 7 日に押した日が無ければ、帯にはインクなしの今日の判子だけを置く
- 読込: 一覧が出るまで待つ。スケルトンは必須にしない
- エラー: 「読み込めませんでした」+ 再試行（現状どおり）
