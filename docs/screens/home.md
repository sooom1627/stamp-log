# ホーム

## 目的 / 対応 Story

スタンプを押す起点。ラリーを一覧し、作成し、ワンタップで押す。収集数と直近の活動日を見渡す。全件はラリー詳細。

- S-001 ラリーを作成する
- S-002 ラリーにスタンプを押す
- S-008 ラリーの収集数を見る

## 入りと出

- 入り: タブ「ホーム」。ルート案 `/`
- 出:
  - 「ラリーを作る」→ [create-rally.md](./create-rally.md)
  - 「スタンプを押す」→ その場で付く。トーストから [add-stamp-memo.md](./add-stamp-memo.md)
  - ラリー行タップ → [rally-detail.md](./rally-detail.md)
  - 直下のスタンプ行タップ → [stamp-detail.md](./stamp-detail.md)
- 削除: 確認ダイアログのまま（S-001）。ラリー行の中。

## レイアウト

現状: 中央寄せ。ラリー名、タイプ、「スタンプを押す」、直下に全スタンプ（日時 + メモ）、削除。収集数なし。詳細へ進めない。

目標:

```
ホーム                         [ラリーを作る]

┌─────────────────────────────────┐
│ 今年会った研究者          人    │
│ 12                             │  ← 収集数（目標ありなら 12 / 20）
│ [スタンプを押す]                │
│ Last 7 days                 ˅   │
│ Mon Tue Wed Thu Fri Sat Sun     │
│  ○   ●   ○   ○   ●   ●   ○   │  ← 1回以上押した日だけオレンジ
│                          削除   │
└─────────────────────────────────┘

（同様に次のラリー）

[ ホーム ] [ 記録 ] [ カレンダー ]
```

- ラリー行本体のタップは詳細。ボタン（押す / 削除）は行タップと分けて取る。
- 初期表示は今日を含む直近7日。曜日は英語3文字表記で、古い日から今日へ並べる。
- `Last 7 days` を開くと直近28日になる。最も古い週が上、最新7日が最下段、今日が右下。
- 0件は薄い丸、1件以上はオレンジの丸。同日回数による濃淡や数字は出さない。
- これは表示デザインだけの変更とし、スタンプの保存、メモ、Query、DB、画面遷移は変えない。

### アコーディオン

- 展開時は過去21日を最新7日の上へ追加し、最新7日と後続ラリーを約180msで滑らかに移動する。
- 過去21日は展開時180msのフェード + 4px移動、折りたたみ時120msのフェード。シェブロンは150msで回転する。
- バウンド、ハプティクスは使わない。開閉の連打をロックしない。
- Reduce Motion 時は移動、回転、フェード、レイアウト補間を省く。

## 出すデータ

- ラリー: 名称、タイプ（人 / 場所 / 行動）
- 収集数。目標があるときだけ `現在 / 目標`
- 直近28日分のスタンプ日時（ホームでは日ごとの記録有無だけを表示）

## 空 / 読込 / エラー

- 空: ラリーが無い。「ラリーを作る」だけ見える
- 読込: 一覧が出るまで待つ。スケルトンは必須にしない
- エラー: 「読み込めませんでした」+ 再試行（現状どおり）

## 対象外

- 日ごとの回数、日時、メモの表示
- 目標達成時の見た目（必要になったら rally-detail 側で扱う）
