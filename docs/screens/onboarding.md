# オンボーディング

## 目的 / 対応 Story

初めて開いた人に、何ができるアプリかを 4 枚で短く伝え、最初のラリーを 1 つ選んで始めてもらう。空のホームで迷わせない。出すのは初回起動のときだけ。

- S-047 初回起動のオンボーディングで、最初のラリーを選んで始める
- S-054 オンボーディングに控えめな動きを入れる

## 入りと出

- 入り: 初回起動。オンボーディングを終えていなければ、ホームの代わりにこの画面が開く。ルート案 `/onboarding`（全画面。タブバーとヘッダーは出さない）
- 出:
  - `Start with {name}` → そのラリーを作り、[home.md](./home.md) へ
  - `I'll make my own` → ラリーを作らずに [home.md](./home.md) へ
- どちらかで終えると「終えた」ことを端末に保存し、次からはホームが開く。途中でアプリを閉じたら、次もここから
- 戻るジェスチャーではホームへ抜けない
- 設定の `About Ato` からも紹介の 4 枚だけを見直せる（下の「設定から見直す」）

## レイアウト

紹介（4 枚。横にめくれる）:

```
                          Skip   ← 紹介の 4 枚だけ
┌─────────────────────────────┐
│                             │
│          （絵）              │
│                             │
└─────────────────────────────┘
(マーク) Ato                      ← 1 枚目だけ
Look back.                       ← 見出し（大）
It's all there.
Stamp what you collect, …        ← 説明（小）
🔒 No account. Everything stays   ← 1 枚目だけ
   on your phone.

● ━ ● ●                [<] [Next >]   ← ページの点、Back（2〜4 枚目）、Next
```

| 枚  | 見出し                                     | 絵                                                                          |
| --- | ------------------------------------------ | --------------------------------------------------------------------------- |
| 1   | Look back. It's all there.                 | 6 × 6 のドットに、ところどころ傾いたスタンプと、点線の今日                  |
| 2   | Collect anything — people, places, moments | ラリーの例のチップを、行ごとにずらして並べる                                |
| 3   | One tap. That's it.                        | ＋ を押すとスタンプが付き、1 週間のドットとトーストが変わるタイル（試せる） |
| 4   | No streaks to keep.                        | 1 つのラリーのスタンプを日付順に縦に並べる。間隔は不揃いで、間はただの余白  |

- 横にスワイプしてもめくれる。`Next` で次へ、`Back` で前へ。4 枚目の `Next` と、1〜4 枚目の `Skip` は「最初に集めるもの」へ
- 3 枚目のタイルは試すだけで、何も保存しない

最初に集めるもの:

```
            Last step                    ← 小さい補足（アクセント色）
   What will you collect first?          ← 見出し（大、中央）
Start with one. You can rename it or make your own anytime.

  ┌──────┐ ┌────────────┐ ┌──────┐
  │      │ │ October 25 │ │      │     ← テンプレートごとのホームのプレビュー。
  │ (前) │ │ 今日のカード│ │ (次) │        選んだカードが中央に来て、左右がのぞく
  │      │ │ タイル + New│ │      │
  └──────┘ └────────────┘ └──────┘
        (🏃) ( ☕ ) ( 🤝 ) ( 📚 )         ← 絵文字のチップ。押すとそのテンプレートを選ぶ

[        Start with Morning run      ]
           I'll make my own
```

- 初めは 1 つ目のテンプレートを選んだ状態。カードを横にスワイプして止まったものか、押したカードかチップを選ぶ
- テンプレートは 🏃 Morning run / ☕ Cafés I visited / 🤝 People I met / 📚 Books I read。作ったラリーの名前と絵文字は、後で [edit-rally.md](./edit-rally.md) から変えられる

## 動き

控えめに動かす。止まらない動きは 2 枚目のチップの流れだけ。

| どこ               | 動き                                                                                                     | 長さ              |
| ------------------ | -------------------------------------------------------------------------------------------------------- | ----------------- |
| ページの点         | 今のページの点が横に伸び、前の点が縮む                                                                   | 220ms             |
| 3 枚目の ＋        | 押すとボタンが一瞬沈んで戻り、今日の点がふくらみ、トーストが下から出る（押し直して外すときは動かさない） | 約 350ms          |
| 最初に集めるものへ | 紹介からフェードで入る                                                                                   | 200ms             |
| 見本のカード       | 大きさと濃さが、スクロールの位置に合わせて連続で変わる（中央で 1、隣で 0.92 倍・濃さ 0.55）              | 指に追従          |
| 1 枚目の絵         | 5 つのスタンプが少し大きい所から順に押され、最後に今日の点線が出る                                       | 約 1.2 秒         |
| 2 枚目の絵（入り） | チップの行が左右から少しずれて寄る                                                                       | 約 0.7 秒         |
| 2 枚目の絵（流れ） | チップの行が行ごとに交互の向きで、ゆっくり横に流れ続ける。端は途切れない                                 | 1 秒に約 15〜20px |
| 3 枚目の絵         | タイルが少し下から出る                                                                                   | 400ms             |
| 4 枚目の絵         | 線が上から伸び、スタンプとメモが日付順に出る                                                             | 約 1.2 秒         |

- 絵の入りの動きは、そのページを初めて開いたときに一度だけ。戻って見直すときは止まった絵で出す
- ページ送りのスライドは変えない
- 端末の「視差効果を減らす」がオンなら、どれも動かさず完成した形で出す。見本のカードの大きさと濃さは指の位置に合わせるだけなので、そのまま変わる

## 設定から見直す

- 入り: [settings.md](./settings.md) の `About Ato`。ルート `/about-ato`（全画面のモーダル。設定シートの上に出る）
- 紹介の 4 枚と同じ絵と文言、同じ動き。スワイプ、`Next`、`Back` も同じ
- 右上は `Skip` の代わりに `Close`。4 枚目の主ボタンは `Next` の代わりに `Done`（矢印なし）。どちらも設定シートに戻る
- 最初に集めるものは出さない。ラリーは作らず、終えたかどうかの保存も変えない

## 出すデータ

- 保存: 選んだテンプレートの名前と絵文字でラリーを 1 つ作る。終えたかどうかは端末の設定として持ち、書き出しファイルには入れない

## 空 / 読込 / エラー

- 読込: なし
- エラー: ラリーの作成に失敗したら共通のトーストを出し、この画面に留まる（終えたことにしない）
