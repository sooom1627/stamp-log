# Logs の日

## 目的 / 対応 Story

Logs のカレンダーから選んだ日に、全ラリーで押したスタンプを見る。同じ日でもどのラリーのスタンプかが分かる。

- S-012 特定の日の記録を見る

ラリー詳細の [rally-day.md](./rally-day.md) とは別の画面。こちらは全ラリー横断で、過去スタンプは足せない。

## 入りと出

- 入り: [records-timeline.md](./records-timeline.md) のカレンダーで記録がある日付を押す。ルート案 `/logs-day?date=YYYY-MM-DD`（formSheet）
- 出:
  - 閉じる（シートを下げる）→ Logs
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこのシートに留まる（記録が無くなれば空の表示へ）
- `date` が不正（形式違い・未来日）ならシートを閉じる

## レイアウト

```
            ───                     ← グラバー（ネイティブのヘッダーは出さない）
Saturday                            ← 補足行（小）
Oct 3, 2026                         ← 見出し（大）

☕ 行ったカフェ      4:20 PM     …  ← ラリー名（太字）と時刻。… から Edit / Delete
   駅前の新しい店。混んでいた        ← メモは全文

🔬 今年会った研究者  1:05 PM     …
   学会のポスター発表で話した

🏃 週末のランニング  7:10 AM     …
   no memo                         ← メモなし
```

- 見出しは曜日（小）と日付（大）。日付は年を付ける（[rally-day.md](./rally-day.md) と同じ）
- その日の全ラリーのスタンプを新しい順に並べる
- 投稿は Logs のタイムラインと同じ形（ラリー絵文字のアイコン、ラリー名（太字）と時刻、メモ全文。無ければ `no memo`）。日付は見出しにあるので時刻だけ出す
- 投稿はカードにまとめず、[rally-day.md](./rally-day.md) と同じく並べる（1 日分だけなので見出しが日付を兼ねる）
- タイプ（人 / 場所 / 行動）は出さない
- formSheet なのでタブバーは出さない
- 件数が多くシートに収まらないときは、曜日と日付の見出しをシートの上に残し、投稿だけをスクロールする

## 出すデータ

- 選んだ日付（曜日付き）
- その日のスタンプ: 時刻、メモ全文（あれば）
- スタンプが属するラリー: 絵文字、名称

## 空 / 読込 / エラー

- 空: 記録のない日は開かない。開いている間に全件を消したら「No stamps on this day」
- 読込: 出るまで待つ
- エラー: 読めないときはメッセージ + 再試行

## 未決事項

- 投稿を押した先（[records-timeline.md](./records-timeline.md) と同じ扱い）
