# ラリーを編集する

## 目的 / 対応 Story

作成済みラリーの名称・絵文字・タイプを後から直す。集めたスタンプはそのまま残す。

- S-013 ラリーを編集する

目標数の入力欄は S-009、「1 日 1 回 / 何回でも」の設定は S-026 でこのシートに足す。

## 入りと出

- 入り: [rally-detail.md](./rally-detail.md) のヘッダー右の「…」メニュー →「Edit rally」。ルート `/edit-rally?rallyId=`（formSheet）
- 出: 保存成功でシートを閉じ、ラリー詳細に戻る。シートを下ろしたらキャンセル（変更は捨てる）

## レイアウト

[create-rally.md](./create-rally.md) と同じ並び。初期値は保存済みの値。

```
            ───                 ← グラバー（ネイティブのヘッダーは出さない）
ラリーを編集                    ← 見出し（大）

タイプ    ( 人 )  ( 場所 )  ( 行動 )

絵文字    [ 🗼 ] タップして変更

名称
[ 今年会った研究者            ]

            [ 保存 ]
```

- 名称が空（空白のみ）のとき保存できない
- タイプはスタンプの有無にかかわらず変えられる
- タイプを変えても絵文字は追随しない（保存済みの絵文字はユーザーが選んだものとして扱う）
- 絵文字をタップすると絵文字 Picker が開き、1 つ選べる
- シートは入力欄と保存ボタンを含む内容の高さに合わせる
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: `rallyId`、タイプ、絵文字、名称
- 初期表示: そのラリーのタイプ、絵文字、名称
- 保存後: ラリー詳細（見出しの絵文字と名称、カレンダーの印、投稿アイコン）とホーム（ラリーのタイル、タイプ別集計）に反映する。スタンプは変わらない

## 空 / 読込 / エラー

- 空: 無し（既存のラリーを開く）
- 読込: ラリーが出るまで待つ
- エラー: 存在しない / 不正な `rallyId` ならシートを閉じる。mutation 失敗はトーストを出してシートに留まる
