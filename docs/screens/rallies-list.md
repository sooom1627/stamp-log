# ラリー一覧

## 目的 / 対応 Story

ラリーを全部見渡す。ホームに出ているラリーをお気に入りだけに絞って見たり、アーカイブしてホームから外したラリーを見返したりする。押す操作はホームと同じタイルで行える。

- S-039 ラリーを一覧で見渡し、使わないラリーをアーカイブして Home から外す

## 入りと出

- 入り: ホームの `View All`。ルート案 `/rallies-list`（ホームのスタックに積む）
- 出:
  - 戻る → ホーム
  - ヘッダー右の `＋` → [create-rally.md](./create-rally.md)（formSheet）。作って閉じるとこの画面に戻る
  - タイル右上のボタン → その場でスタンプが付く。トーストから [add-stamp-memo.md](./add-stamp-memo.md)（`All` / `Favorites` のみ）
  - タイルの名称部分のタップ → [rally-detail.md](./rally-detail.md)（`/rallies/[id]`）

## レイアウト

```
‹ Home                            (＋)  ← New rally

Your Days

┌──────────────────────────────────┐
│   All   │ Favorites │ Archived   │  ← ネイティブの segmented control
└──────────────────────────────────┘

┌──────────────┐ ┌──────────────┐
│ [🏃]★    (＋) │ │ [🗼]     (✓) │  ← ホームと同じタイル
│ Morning run   │ │ Tokyo towers │
│ 5 stamps      │ │ 10 stamps    │
│ Mo Tu We Th Fr Sa Su │ │ Mo Tu … Su │
│ ·  ·  ·  ·  ●  ·  · │ │ ·  ● … ●  │
└──────────────┘ └──────────────┘
```

- 見出しは `Your Days`（ホームのセクション見出しと同じ語。内部用語の「ラリー」は出さない）
- 見出しの下にネイティブの segmented control で `All / Favorites / Archived` を置く。開くたびに `All` から始め、選んだタブは覚えない
- 一覧を横にスワイプしても隣のタブに切り替わる。左へスワイプで次（`All` → `Favorites` → `Archived`）、右へスワイプで前。端のタブではそれ以上動かない。縦のスクロールの途中では切り替えない。segmented control の選択も合わせて変わる
- タブの中身
  - `All`: アーカイブしていないラリー（ホームのタイルと同じ集まり）
  - `Favorites`: アーカイブしていないお気に入りのラリー
  - `Archived`: アーカイブしたラリー
- 並びは 3 つのタブとも [home.md](./home.md) のタイルと同じ（お気に入りが先、それぞれ収集数の多い順、同数なら新しく作ったラリーが先）。開いている間は並びを変えず、ほかの画面から戻ったときに並べ直す。並び順を選ぶ操作は置かない
- タイルは [home.md](./home.md) と同じ 2 列のタイル（絵文字、お気に入りの星、名称、収集数、直近 7 日のドット、右上の押すボタン）
- `Archived` のタイルには押すボタンを出さない。名称のタップで詳細へ進み、アーカイブの解除は詳細の「…」で行う（[rally-detail.md](./rally-detail.md)）
- ヘッダー右に `＋` のボタン（SF Symbols `plus`）を置き、ラリー作成を開く。読み上げは `Create rally`（ホームの `New rally` タイルと同じ）。一覧の中に `New rally` タイルは置かない
- 作ったラリーはスタンプが 0 件なので、閉じて戻ったときの並べ直しで `All` のお気に入りでないラリーの最後に入る

## 出すデータ

- ラリー: 名称、絵文字、お気に入りかどうか、アーカイブしたかどうか
- 収集数と、直近 7 日分のスタンプ日時（タイルでは日ごとの記録有無だけを表示）

## 空 / 読込 / エラー

- 空: タブごとに 1 行の文言を出す
  - `All`: `No rallies`
  - `Favorites`: `No favorites yet`
  - `Archived`: `No archived rallies`
- 読込: 一覧が出るまで待つ。スケルトンは必須にしない
- エラー: 「読み込めませんでした」+ 再試行（ホームと同じ）

## 対象外

- 並び順の切り替え、名前での検索
- 一覧からのアーカイブ・お気に入り・削除の操作（どれもラリー詳細で行う）
