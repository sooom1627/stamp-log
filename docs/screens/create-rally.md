# ラリーを作る

## 目的 / 対応 Story

名称とタイプでラリーを作る。任意で目標数を付けられる。

- S-001 ラリーを作成する
- S-009 目標数に対する進捗を見る（作成時の入力。編集は E-005）

## 入りと出

- 入り: ホームの「ラリーを作る」。ルート案 `/create-rally`（formSheet）
- 出: 保存成功で閉じ、ホームに戻る。シートを下ろしてもキャンセル

## レイアウト

現状: 見出し、タイプ（人 / 場所 / 行動）、名称、保存。目標数なし。

目標:

```
ラリーを作る

タイプ    ( 人 )  ( 場所 )  ( 行動 )

名称
[ 記録したい人を入力          ]

目標数（任意）
[                           ]

            [ 保存 ]
```

- タイプで名称プレースホルダが変わる（現状どおり）
- 目標数は任意。空なら目標なし
- 名称が空（空白のみ）のとき保存できない（現状どおり）
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: タイプ、名称、目標数（空 = なし）
- 保存後: ホーム一覧に名称・タイプ。目標があればホーム / 詳細の収集数に使う

## 空 / 読込 / エラー

- 空: 初期はタイプ選択済み（現状のデフォルト）、名称空、目標空
- 読込: なし（新規）
- エラー: mutation 失敗はトースト（現状の Query 方針）

## 未決事項

- 目標数の入力 UI（数値フィールドで足りる。ステッパーは必須にしない）
- 目標数の上限。未指定なら実装時に妥当な上限を置く
