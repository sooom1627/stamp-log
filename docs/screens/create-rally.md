# ラリーを作る

## 目的 / 対応 Story

名称と絵文字でラリーを作る。

- S-001 ラリーを作成する
- S-023 ラリーに絵文字を付ける
- S-040 ラリーを作るときにタイプを選ばずに済む
- S-039 ラリーを一覧で見渡し、使わないラリーをアーカイブして Home から外す（一覧からの入り）
- S-058 記録を画像にして SNS に送り、見た人が同じラリーを始められる（共有のリンクからの入り）

## 入りと出

- 入り: ホームの「ラリーを作る」、[rallies-list.md](./rallies-list.md) のヘッダー右の `＋`。ルート案 `/create-rally`（formSheet）
- 入り（共有のリンク）: ほかの人が共有したラリーのリンク `https://<ドメイン>/create-rally?name=…&emoji=…` を Ato のある iPhone で開く。名前と絵文字が入った状態で開く
- 出: 保存成功で閉じ、開いた画面（ホームかラリー一覧）に戻る。シートを下ろしてもキャンセル

## レイアウト

現状: 見出し、絵文字、名称、保存。

目標:

```
            ───                 ← グラバー（ネイティブのヘッダーは出さない）
ラリーを作る                    ← 見出し（大）

絵文字    [ ✨ ] タップして変更

名称
[ Enter a rally name         ]

            [ 保存 ]
```

- 絵文字の初期値は ✨
- 共有のリンクから開いたときは、名前と絵文字にリンクの値を入れて開く。`Save` を押すまでラリーはできない。入れた値はふつうに直せる
- リンクの名前が空・長すぎる（ラリーの名前の上限より長い）、または絵文字が 1 つの絵文字でないときは、このシートを出さずにホームを開く
- 絵文字をタップすると絵文字Pickerが開き、1つ選べる
- 名称が空（空白のみ）のとき保存できない（現状どおり）
- シートは入力欄と保存ボタンを含む内容の高さに合わせる
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: 絵文字、名称
- 保存後: ホーム一覧に名称・絵文字

## 空 / 読込 / エラー

- 空: 絵文字 ✨、名称空
- 読込: なし（新規）
- エラー: mutation 失敗はトースト（現状の Query 方針）
