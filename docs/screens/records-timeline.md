# 記録（Logs）

## 目的 / 対応 Story

ラリーをまたいで振り返る。上のカレンダーでスタンプを押した日を見渡し、日付からその日の記録を開く。下のタイムラインで押したスタンプを新しい順に投稿として見る。投稿はラリー詳細のタイムラインと同じ形で、どのラリーのスタンプかが分かる。投稿は後から編集・削除できる。タイムラインは Album に切り替えると、付けた写真を日とラリーごとにまとめて新しい順に見られる。

- S-010 すべての記録を時系列で見る
- S-011 記録がある日をカレンダーで見る
- S-012 特定の日の記録を見る
- S-035 スタンプを押すときに写真を最大 4 枚付けられる（投稿の写真マーク）
- S-037 写真を全画面で見て、Logs とラリー詳細のアルバムでも見る（写真マークから全画面、Stamps / Album の切り替え）
- S-043 Stamps と Album を、指についてくるページ送りで切り替える

## 入りと出

- 入り: タブ「Logs」。ルート `/records`
- 出:
  - カレンダーの記録がある日付 → [logs-day.md](./logs-day.md)（formSheet）
  - カレンダーの月見出し → 年月 Picker
  - 投稿タップ → [rally-detail.md](./rally-detail.md)（その投稿のラリー）
  - 投稿の写真マーク → [stamp-photos.md](./stamp-photos.md)（そのスタンプの 1 枚目から。全画面モーダル）
  - Album のマス → [stamp-photos.md](./stamp-photos.md)（そのマスの 1 枚目から）
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこの画面に留まる

## レイアウト

```
Logs                                ← 大見出し
Your days, one stamp at a time      ← その下に一言（日付は出さない）

┌──────────────────────────────────┐
│ ‹       October 2026 ▾        ›  │  ← 見出しタップで年月 Picker
│ Mon Tue Wed Thu Fri Sat Sun      │
│ 🔬  🏃  ☕+2 🔬+1  9  (10)  11    │  ← 初期は今日を含む週。+N は右下に重ねる
│          Show month ⌄            │  ← 押すと月全体、もう一度で週に戻る
└──────────────────────────────────┘

[ Stamps · 48 | Album · 23 ]       ← 切り替え。初期は Stamps

Today                   Sat, Oct 10  ← 日の見出し（カードの上）
┌──────────────────────────────────┐
│ 🔬 今年会った研究者  8:15 PM [▣ 3] … │  ← ラリー名（太字）と時刻。写真があれば写真アイコンと枚数。… から Edit / Delete
│    研究室で話した                 │  ← メモは全文
│ ──────────────────────────────── │  ← 同じ日の投稿は線で区切る
│ ☕ 行ったカフェ      1:30 PM   …  │
│    no memo                       │  ← メモなし
└──────────────────────────────────┘  ← 1 日分を 1 枚のカードにまとめる

Thu, Oct 8                          ← 今日・昨日以外は曜日付きの日付だけ
┌──────────────────────────────────┐
│ 🏃 週末のランニング  6:40 AM   …  │
│    no memo                       │
└──────────────────────────────────┘
```

Album に切り替えたとき（カレンダーまでは同じ）:

```
[ Stamps · 48 | Album · 23 ]
┌──────────┬──────────┬──────────┐
│          │          │          │
│ 🔬  [▣ 3]│ ☕       │ 🏃  [▣ 2]│  ← 3 列の正方形。1 マス = その日 × そのラリー
├──────────┼──────────┼──────────┤     左下にラリーの絵文字、2 枚以上なら右下に枚数
│          │          │          │
│ 🔬       │ 🗼  [▣ 5]│ ☕  [▣ 2]│
└──────────┴──────────┴──────────┘

[ Home ] [ Logs ]
```

- ルートはこのタブ。上から 一言、カレンダー、切り替え、タイムラインか Album の順に、1 本の縦スクロールに並べる（インスタグラムのプロフィール画面の形。[rally-detail.md](./rally-detail.md) と同じ）。下へスクロールすると一言とカレンダーは上に流れて隠れ、切り替えは画面の上端に貼り付いて残る。切り替えより下は 2 ページ（Stamps / Album）のページ送り
- カレンダー
  - 面はラリー詳細のカレンダーと同じ（白い面 1 枚）。週 / 月の切り替え、‹ › での送り、年月 Picker もラリー詳細と同じ
  - 日付のマスはラリー詳細と同じ。記録がある日は日付の代わりにその日最後に押したラリーの絵文字、今日は枠
  - その日のスタンプが 2 件以上なら、マスの右下に「+N」を重ねる。N は出している絵文字のほかに押したスタンプの数
  - 記録がある日付を押すと、その日の記録を [logs-day.md](./logs-day.md) で開く。記録のない日は押せない
  - カレンダーとタイムラインは連動しない。月や週を送ってもタイムラインは変わらない
- 切り替え
  - カレンダーの下に `Stamps · 件数` と `Album · 枚数` の 2 つを並べる。件数は全スタンプの数、枚数は全写真の数
  - 画面を開くたびに Stamps から始める（選んだ側は覚えない）
  - 切り替えより下（タイムラインか Album、空の案内）はページ送り。横にスワイプするとページが指について動き、離すと隣のページか元のページに吸い付く。左へで Album、右へで Stamps。ページが変わると切り替えの選択も変わる
  - 切り替えを押すと、そのページへ横に動いて移る
  - 縦のスクロールは画面全体で 1 本。ページを替えてもスクロールの位置はそのまま（ページごとには覚えない）
  - スタンプが 1 件も無いときは切り替えもページも出さず、カレンダーの下に No stamps yet だけを出す
  - カレンダーはどちらを選んでいても同じ
- タイムライン（Stamps）
  - 全ラリーのスタンプを新しいものから過去へ並べる
  - 1 日分の投稿を 1 枚のカード（面）にまとめ、カードの上に日の見出しを置く。カードの中の投稿は線で区切る。見出しは貼り付けず、投稿と一緒に流れる。書き方は [design.md](../design.md)「スタンプの日時」
  - 投稿はラリー詳細のタイムラインと同じ部品
    - ラリー絵文字のアイコン、ラリー名（太字）と時刻（薄く）、メモ全文（無ければ `no memo`）
    - 写真が付いていれば、時刻の隣に写真アイコンと枚数のマーク（[rally-detail.md](./rally-detail.md) と同じ）。マークを押すと、そのスタンプの写真を [stamp-photos.md](./stamp-photos.md) で 1 枚目から開く。読み上げは `3 photos. Show photos` のように枚数を含める
    - 日付は見出しに任せ、投稿には出さない
  - 投稿はカードにせず、画面の地に直接並べる（ラリー詳細と同じ）
  - 各投稿の右端の「…」から「Edit」「Delete」。動きはラリー詳細と同じ。Delete はタイムラインとカレンダーから消える
  - 投稿のマーク以外を押すと、そのラリーの詳細へ進む
- Album
  - 全ラリーの写真を、その日（端末の日付）× そのラリーで 1 マスにまとめ、3 列の正方形のグリッドに並べる。同じ日でもラリーが違えば別のマス
  - マスの写真はそのまとまりの 1 枚目（スタンプの古い順、同じスタンプの中は付けた順で最初）
  - 並びは新しい日が先。同じ日のマスは、そのまとまりで最後に押したスタンプが新しい順
  - 各マスの左下にラリーの絵文字を出す。写真が 2 枚以上なら右下に写真アイコンと枚数を出す
  - マスを押すと [stamp-photos.md](./stamp-photos.md) でそのマスの 1 枚目から開き、そのまとまりの写真をすべてめくれる
  - 読み上げは枚数、ラリー名、日付を含める。例: `Open 3 photos, 今年会った研究者, Oct 10`（1 枚なら `Open photo, 今年会った研究者, Oct 10`）。日付は時刻を付けず `Oct 10`、今年以外は年を付けて `Oct 10, 2025`（[design.md](../design.md)「スタンプの日時」から時刻を除いた形）
- 絞り込みは置かない
- 検索は置かない
- タブバーは残す（[design.md](../design.md) IA）

## 出すデータ

- カレンダー: 表示中の年月と週 / 月、その範囲で記録がある日付と、その日最後に押したラリーの絵文字、その日の件数
- スタンプ: 日時、メモ全文（あれば）、写真の枚数
- Album: 全スタンプの写真（一覧用の小さい画像。無い写真は元の画像）を日 × ラリーでまとめたもの（1 枚目、枚数、日付）、そのラリーの絵文字と名称、写真の総数
- スタンプが属するラリー: 絵文字、名称

## 空 / 読込 / エラー

- 空: カレンダーは出て記録日が無いだけ。タイムラインは「No stamps yet」。写真が 1 枚も無いときの Album は「No photos yet」
- 読込: 出るまで待つ
- エラー: 一覧の失敗はホームと同じ（メッセージ + 再試行）
