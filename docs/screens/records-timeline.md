# 記録（Logs）

## 目的 / 対応 Story

ラリーをまたいで振り返る。上のカレンダーでスタンプを押した日を見渡し、日付からその日の記録を開く。下のタイムラインで押したスタンプを新しい順に投稿として見る。投稿はラリー詳細のタイムラインと同じ形で、どのラリーのスタンプかが分かる。投稿は後から編集・削除できる。

- S-010 すべての記録を時系列で見る
- S-011 記録がある日をカレンダーで見る
- S-012 特定の日の記録を見る

## 入りと出

- 入り: タブ「Logs」。ルート `/records`
- 出:
  - カレンダーの記録がある日付 → [logs-day.md](./logs-day.md)（formSheet）
  - カレンダーの月見出し → 年月 Picker
  - 投稿タップ → [rally-detail.md](./rally-detail.md)（その投稿のラリー）
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこの画面に留まる

## レイアウト

```
Logs                                ← 大見出し
Your days, one stamp at a time      ← その下に一言（日付は出さない）

┌──────────────────────────────────┐
│ ‹       October 2026 ▾        ›  │  ← 見出しタップで年月 Picker
│ Mon Tue Wed Thu Fri Sat Sun      │
│ 🔬  🏃  ☕+2 🔬+1  9  (10)  11    │  ← 初期は今日を含む週。+N は右下に重ねる
│          Show month ⌄            │  ← 押すと月全体、もう一度で週に戻る
└──────────────────────────────────┘

Stamps                          48

Today                   Sat, Oct 10  ← 日の見出し（カードの上）
┌──────────────────────────────────┐
│ 🔬 今年会った研究者  8:15 PM   …  │  ← ラリー名（太字）と時刻。… から Edit / Delete
│    研究室で話した                 │  ← メモは全文
│ ──────────────────────────────── │  ← 同じ日の投稿は線で区切る
│ ☕ 行ったカフェ      1:30 PM   …  │
│    no memo                       │  ← メモなし
└──────────────────────────────────┘  ← 1 日分を 1 枚のカードにまとめる

Thu, Oct 8                          ← 今日・昨日以外は曜日付きの日付だけ
┌──────────────────────────────────┐
│ 🏃 週末のランニング  6:40 AM   …  │
│    no memo                       │
└──────────────────────────────────┘

[ Home ] [ Logs ]
```

- ルートはこのタブ。上から カレンダー、タイムライン。同じスクロールに並べる
- カレンダー
  - 面はラリー詳細のカレンダーと同じ（白い面 1 枚）。週 / 月の切り替え、‹ › での送り、年月 Picker もラリー詳細と同じ
  - 日付のマスはラリー詳細と同じ。記録がある日は日付の代わりにその日最後に押したラリーの絵文字、今日は枠
  - その日のスタンプが 2 件以上なら、マスの右下に「+N」を重ねる。N は出している絵文字のほかに押したスタンプの数
  - 記録がある日付を押すと、その日の記録を [logs-day.md](./logs-day.md) で開く。記録のない日は押せない
  - カレンダーとタイムラインは連動しない。月や週を送ってもタイムラインは変わらない
- タイムライン
  - 全ラリーのスタンプを新しいものから過去へ並べる。見出し「Stamps」と全件数
  - 1 日分の投稿を 1 枚のカード（面）にまとめ、カードの上に日の見出しを置く。カードの中の投稿は線で区切る。見出しは貼り付けず、投稿と一緒に流れる。書き方は [design.md](../design.md)「スタンプの日時」
  - 投稿はラリー詳細のタイムラインと同じ部品
    - ラリー絵文字のアイコン、ラリー名（太字）と時刻（薄く）、メモ全文（無ければ `no memo`）
    - 日付は見出しに任せ、投稿には出さない
  - 投稿はカードにせず、画面の地に直接並べる（ラリー詳細と同じ）
  - 各投稿の右端の「…」から「Edit」「Delete」。動きはラリー詳細と同じ。Delete はタイムラインとカレンダーから消える
  - 投稿を押すと、そのラリーの詳細へ進む
- 絞り込みは置かない
- 検索は置かない
- タブバーは残す（[design.md](../design.md) IA）

## 出すデータ

- カレンダー: 表示中の年月と週 / 月、その範囲で記録がある日付と、その日最後に押したラリーの絵文字、その日の件数
- スタンプ: 日時、メモ全文（あれば）
- スタンプが属するラリー: 絵文字、名称

## 空 / 読込 / エラー

- 空: カレンダーは出て記録日が無いだけ。タイムラインは「No stamps yet」
- 読込: 出るまで待つ
- エラー: 一覧の失敗はホームと同じ（メッセージ + 再試行）
