# 記録（タイムライン）

骨格（E-004 / S-010）。配置・遷移・空状態まで。ワイヤーの denseness は実装着手時に足す。

## 目的 / 対応 Story

ラリーをまたいで、押したスタンプを新しい順で見る。タイプの違いが分かり、タイプで絞り込める。

- S-010 すべての記録を時系列で見る

## 入りと出

- 入り: タブ「記録」。ルート案 `/records`
- 出: 行タップ → [stamp-detail.md](./stamp-detail.md)
- ラリー名から [rally-detail.md](./rally-detail.md) へ進めてよい

## レイアウト（骨格）

```
記録

[ すべて ] [ 人 ] [ 場所 ] [ 行動 ]

9月20日 11:40    人  今年会った研究者
  メモがあれば一行

9月18日 19:02    場所  東京の美術館
```

- ルートはこのタブの一覧。ホームのコピーではない
- 絞り込みはタイプのみ（今は検索しない）

## 出すデータ

- 日時、タイプ、ラリー名、メモ（あれば一行）

## 空 / 読込 / エラー

- 空（全体）: 「まだスタンプがありません」。ホームへ誘導してよい
- 空（絞り込み）: そのタイプの記録がない、と分かる
- 読込 / エラー: 一覧の失敗はホームと同じ（メッセージ + 再試行）
