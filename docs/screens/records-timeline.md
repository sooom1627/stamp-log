# 記録（タイムライン）

## 目的 / 対応 Story

ラリーをまたいで、押したスタンプを新しい順に投稿として見る。投稿はラリー詳細のタイムラインと同じ形で、どのラリーのスタンプかが分かる。投稿は後から編集・削除できる。

- S-010 すべての記録を時系列で見る

## 入りと出

- 入り: タブ「Logs」。ルート `/records`
- 出:
  - 投稿タップ → [stamp-detail.md](./stamp-detail.md)
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこの画面に留まる

## レイアウト

```
Welcome back                        ← タブルート共通の見出し
8 October, 2026

🔬 Wed, Oct 7  7:02 PM           …  ← … から Edit / Delete
   今年会った研究者                  ← ラリー名
   研究室で話した。次は共同研究の
   話をもう少し詰める                ← メモは全文

🏃 Wed, Oct 7  6:40 AM           …
   週末のランニング
   no memo                          ← メモなし

[ Home ] [ Logs ] [ Calendar ]
```

- ルートはこのタブの一覧。ホームのコピーではない
- 全ラリーのスタンプを新しいものから過去へ並べる
- 投稿はラリー詳細のタイムラインと同じ部品で、日時の下にラリー名の行を足す。ラリー詳細の 1 行目とメモの出し方は変えない
  - ラリー絵文字のアイコン、曜日付きの日付（太字）と時刻（薄く）、ラリー名（アクセント色）、メモ全文（無ければ `no memo`）
  - 日時の書き方は [design.md](../design.md)「スタンプの日時」のラリー詳細と同じ
- 各投稿の右端の「…」から「Edit」「Delete」。動きはラリー詳細と同じ。Delete はタイムラインから消える
- タイプ（人 / 場所 / 行動）は出さず、絞り込みも置かない
- 日ごとの見出しは付けない。日付は各投稿に出す
- 検索は置かない
- タブバーは残す（[design.md](../design.md) IA）

## 出すデータ

- スタンプ: 日時、メモ全文（あれば）
- スタンプが属するラリー: 絵文字、名称

## 空 / 読込 / エラー

- 空: 「No stamps yet」
- 読込: 出るまで待つ
- エラー: 一覧の失敗はホームと同じ（メッセージ + 再試行）
