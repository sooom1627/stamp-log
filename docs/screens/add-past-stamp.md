# 過去の日にスタンプを押す

## 目的 / 対応 Story

忘れた日や後から思い出した体験を、選んだ日時でスタンプとして残す。ワンタップ（いま）とは別経路。操作は formSheet と日付・時刻ピッカーで短く済ませる。

- S-025 過去の日付にスタンプを押す
- S-028 ラリー詳細を見やすく、操作しやすくする（入口の移動と日付の受け渡し）

## 入りと出

- 入り:
  - [rally-detail.md](./rally-detail.md) の右上「…」→「Past stamp」（そのラリーを渡す）
  - [rally-day.md](./rally-day.md) の「Stamp this day」（そのラリーと日付を渡す）
  - ルート `/add-past-stamp?rallyId=&date=`（formSheet）。`date`（`YYYY-MM-DD`）は任意
  - 入口はラリー詳細とラリーの日だけ。スタンプ詳細からは開かない
- 出: 保存成功でシートを閉じ、開いた画面（ラリー詳細、またはラリーの日）に戻る。stamps Query は invalidate され、ラリー詳細の収集数とホーム（週表示・収集数）に選んだ日時で反映される

## レイアウト

[create-rally.md](./create-rally.md) と同様、formSheet は内容の高さに合わせ、保存操作を初期表示で見せる。

```
            ───                 ← グラバー（ネイティブのヘッダーは出さない）
🗼 今年会った研究者             ← 補足行（小。どのラリーに付くか）
過去のスタンプ                  ← 見出し（大）

日付
[  9月 18, 2026        ▼  ]   ← ネイティブ日付ピッカー

時刻
[  11:40               ▼  ]   ← ネイティブ時刻ピッカー

            [ Save ]
```

- ラリーは見出しの上の補足行に絵文字と名前で出す（どのラリーに付くか確認用）
- 日付・時刻を組み合わせたローカル日時を `stampedAt`（ISO）として保存する
- 日付の下限は設けない。ラリー作成日より前の日付も選べる
- 未来の日時は選べない。上限は「いま」（端末の現在日時）
- そのラリーで同じカレンダー日に既にスタンプがある日は保存できない（重複防止。時刻が違っても同一日は不可）。このルールは過去のスタンプだけに適用し、いま押すスタンプはホームの UI 制御のまま
- 保存後の任意メモはホームで押したときと同じトースト（約5秒）→ 任意で [add-stamp-memo.md](./add-stamp-memo.md)。トーストはホームと共通の関数で出す。過去押印専用のメモ画面は作らない
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: `rallyId`、選択した日付と時刻（ローカル）
- 保存後: 新しいスタンプ 1 件（`stampedAt` は選んだ日時）

## 空 / 読込 / エラー

- 空: `date` が無いとき、日付の初期値は「昨日」、時刻の初期値は「12:00」など分かりやすい固定（実装で決めてよい）。`date` があるときは日付をその日にし、時刻の初期値は今日なら今の時刻、過去日なら 12:00。ラリーにスタンプが無くても使える
- 読込: `rallyId` が無効なら保存できない。専用エラー画面は作らない
- エラー: mutation 失敗はトースト。未来日時・同日重複は保存前にバリデーション（インライン or 保存不可）

## 未決事項

- ラリー作成時に「1 日 1 回 / 何回でも」を選べるようにするか。選べるなら、同日ルールはラリー設定に従う

## 実装

- 日時 UI: `@expo/ui/swift-ui` の `DatePicker`（`title` で「ラベル左・値右」の行を SwiftUI に任せる。formSheet 内は create-rally / add-stamp-memo と同様 ScrollView なし）。iOS のみ。Android は対象外（対応時は押してダイアログを開く方式を別途設計）
- 同一ローカル日判定: ホーム activity と同じカレンダー日キー（`src/shared/utils/` の `localDateKey`）でラリー単位に 1 件。`stampedAt` 指定時のみ db 層で enforce し、UI でも保存前に判定する
- 保存 API: `saveStamp` / `useSaveStamp` に任意の `stampedAt` を渡す（専用 mutation はない）
