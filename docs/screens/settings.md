# 設定

## 目的 / 対応 Story

アプリ全体にかかわる操作と情報を 1 か所にまとめる。データの書き出し・読み込み、サポート、プライバシーポリシー、ライセンス、アプリのバージョン。

- S-044 タブルートの Menu から設定シートを開ける

## 入りと出

- 入り: タブルート（ホーム / Logs）のヘッダー右の Menu ボタン。ルート `/settings`（formSheet）
- 出:
  - 閉じる（シートを下げる）→ 元のタブ
  - `Export data` → 全データを書き出したファイルを共有シートで出す
  - `Import data` → ファイルを選び、今のデータを置き換える
  - `Help & support` → サポートページ（外部ブラウザ）
  - `Privacy Policy` → プライバシーポリシーのページ（外部ブラウザ）
  - `Licenses` → 使っているオープンソースのライセンスの一覧

## レイアウト

```
            ───                     ← グラバー（ネイティブのヘッダーは出さない）
Settings                            ← 見出し（大）。補足行は出さない

DATA
╭─────────────────────────────────╮
│ [↑] Export data                 │
│     Save rallies and stamps to a file
├─────────────────────────────────┤
│ [↓] Import data                 │
│     Replace this device's data with a file
╰─────────────────────────────────╯
Photos aren't included in the file yet.

ABOUT
╭─────────────────────────────────╮
│ [?] Help & support           ↗  │
├─────────────────────────────────┤
│ [⛉] Privacy Policy           ↗  │
├─────────────────────────────────┤
│ [≡] Licenses                 ›  │
╰─────────────────────────────────╯

          Stamplog 1.0.0            ← アプリ名とバージョン
```

- 行はグループごとに角丸の面にまとめ、地（canvas）より明るい面（surface）に置く。グループの上に小さい大文字のラベル
- 各行の左にアクセントの淡い下地のアイコン。外部ページを開く行は右に ↗、アプリ内で進む行は右に ›
- `Data` の下に、書き出しに写真が含まれないことを小さく出す
- バージョンは `app.json` の `version`
- formSheet なのでタブバーは出さない

## 出すデータ

- アプリのバージョン

## 空 / 読込 / エラー

- 読み込むデータが無いので空・読込・エラーの表示は無い

## 未決事項

- 各行の動作（書き出し・読み込み・外部ページ・ライセンス一覧）の詳細は、それぞれの Story でこの文書に書き足す
