# ラリーの日

## 目的 / 対応 Story

ラリー詳細のカレンダーから選んだ日に、そのラリーで押したスタンプを見る。記録の無い日は、その日の過去スタンプを足せる。

- S-028 ラリー詳細を見やすく、操作しやすくする

カレンダータブの [day-detail.md](./day-detail.md)（全ラリー横断・スタック画面）とは別の画面。こちらは 1 ラリーに絞った formSheet。

## 入りと出

- 入り: [rally-detail.md](./rally-detail.md) のカレンダーで今日以前の日付を押す。ルート案 `/rally-day?rallyId=&date=YYYY-MM-DD`（formSheet）
- 出:
  - 閉じる（× またはシートを下げる）→ ラリー詳細
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこのシートに留まる（記録が無くなれば空の表示へ）
  - 「Stamp this day」→ [add-past-stamp.md](./add-past-stamp.md)（その日付を渡す）
- `rallyId` か `date` が不正（形式違い・未来日・存在しないラリー）ならシートを閉じる

## レイアウト

```
            ───                     ← グラバー
Friday                         (×)
Sep 18, 2026

🗼 7:02 PM                       …  ← … から Edit / Delete
   研究室で話した。次は共同研究の
   話をもう少し詰める
```

記録が無い日:

```
            ───
Thursday                       (×)
Sep 17, 2026

┌──────────────────────────────────┐
│               🗼                 │  ← 淡いアクセントの面
│       No stamp on this day       │
└──────────────────────────────────┘

[         Stamp this day         ]
```

- 見出しは曜日（小）と日付（大）。日付は年を付ける
- 投稿はラリー詳細のタイムラインと同じ形。日付は見出しにあるので時刻だけ出す
- 記録がある日には「Stamp this day」を置かない（同じラリー・同じ日の過去スタンプは保存できないため。[add-past-stamp.md](./add-past-stamp.md)）
- 「Stamp this day」は過去スタンプの formSheet をその日付入りで開く。時刻はそこで選ぶ（今日なら初期値は今の時刻）
- formSheet なのでタブバーは出さない

## 出すデータ

- 選んだ日付（曜日付き）
- そのラリーのその日のスタンプ: 時刻、メモ全文（あれば）

## 空 / 読込 / エラー

- 空: 「No stamp on this day」と「Stamp this day」
- 読込: 出るまで待つ
- エラー: 読めないときはメッセージ + 再試行
