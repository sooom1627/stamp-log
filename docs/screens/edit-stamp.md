# スタンプを編集する

## 目的 / 対応 Story

押したスタンプの日時・メモ・写真を後から直す。誤った日時の修正、メモの追加・変更・削除、写真の付け忘れや選び間違いの修正に使う。操作は formSheet と日付・時刻ピッカーで短く済ませる。

- S-006 ラリーの内容を見る（ラリー詳細のタイムラインからの編集）
- S-014 スタンプを編集する
- S-036 スタンプの写真を後から足す・外す

## 入りと出

- 入り: [rally-detail.md](./rally-detail.md) のタイムラインの投稿の「…」メニュー →「Edit」。ルート `/edit-stamp?stampId=`（formSheet）
- 出: 保存成功でシートを閉じ、ラリー詳細に戻る。stamps Query は invalidate され、タイムライン（並び順を含む）、カレンダーの印、収集数、ホームに反映される。シートを下ろしたら変更は捨てる

## レイアウト

[add-past-stamp.md](./add-past-stamp.md) と同様、formSheet は内容の高さに合わせ、保存操作を初期表示で見せる。

```
            ───                 ← グラバー（ネイティブのヘッダーは出さない）
🗼 今年会った研究者             ← 補足行（小）
スタンプを編集                  ← 見出し（大）

日付
[  Sep 18, 2026        ▼  ]   ← ネイティブ日付ピッカー

時刻
[  11:40 AM            ▼  ]   ← ネイティブ時刻ピッカー

メモ
[ 研究室で話した              ]   ← 複数行

Photos                     2 / 4  ← 写真の枚数 / 上限
┌────┐ ┌────┐ ┌ ─ ─┐
│ 🖼 ×│ │ 🖼 ×│ │ +  │              ← 今の写真（× で外す）と Add。4 列に並べる
└────┘ └────┘ └ ─ ─┘

            [ Save ]
```

- ラリー名称はシート内に一行でよい（どのラリーのスタンプか確認用）。ラリーは変えない（別のラリーへは移せない）
- 日付・時刻・メモ・写真の初期値は、そのスタンプの今の値
- 日付・時刻を組み合わせたローカル日時を `stampedAt`（ISO）として保存する
- 未来の日時は選べない。上限は「いま」（端末の現在日時）
- そのラリーで同じカレンダー日に別のスタンプがある日には保存できない（編集中のスタンプ自身は数えない）。過去のスタンプと同じ重複防止
- メモは前後の空白を除いて空なら、メモなしとして保存する（一度付けたメモを消せる）
- 写真欄は [add-stamp-memo.md](./add-stamp-memo.md) と同じ形。写真ライブラリから合計 4 枚まで足せ、4 枚のときは Add を出さない。足した写真は末尾に並ぶ。足した写真もアプリに保存するときに EXIF を除く
- 外した写真は、保存したときにアプリからも消える。保存せずにシートを下ろしたら写真は変わらない
- Save は、日時（分単位）・メモ（前後の空白を除く）・写真（並びを含む）のどれかが最初の値から変わったときだけ押せる。変えて元に戻したら押せない
- formSheet なのでタブバーは出さない

## 出すデータ

- 入力: `stampId`、選択した日付と時刻（ローカル）、メモ、写真（残す写真と足す写真。合計 0〜4 枚）
- 初期表示: そのスタンプの日時、メモ、写真、所属ラリーの名称
- 保存後: 同じスタンプ 1 件の `stampedAt`・`memo`・写真が変わる（id とラリーは変わらない）。投稿の写真マークは保存後の枚数になり、0 枚なら消える

## 空 / 読込 / エラー

- 空: メモが無いスタンプはメモ欄が空（プレースホルダのみ）。写真が無いスタンプは `0 / 4` と Add だけ
- 読込: スタンプが読めるまで待つ。`stampId` が不正、またはそのスタンプが存在しないならシートを閉じる。専用エラー画面は作らない
- エラー: mutation 失敗はトースト（日時・メモ・写真のどれも変わらない）。未来日時・同日重複は保存前にバリデーション（インライン or 保存不可）
