# ラリー詳細

## 目的 / 対応 Story

そのラリーに押したスタンプを新しい順で全部見る。収集数と、目標があれば進捗も見る。スタンプを選ぶと詳細へ。

- S-006 ラリーの内容を見る
- S-008 ラリーの収集数を見る
- S-009 目標数に対する進捗を見る
- S-025 過去の日付にスタンプを押す

## 入りと出

- 入り: ホームのラリー行タップ。ルート案 `/rallies/[id]`
- 出:
  - 戻る → 元のタブ
  - スタンプ行タップ → [stamp-detail.md](./stamp-detail.md)
  - 「過去のスタンプ」→ [add-past-stamp.md](./add-past-stamp.md)（formSheet）
- 「いま」スタンプはホームのワンタップのまま。過去日だけこの画面から formSheet で足す

## レイアウト

現状: 絵文字、名称、収集数、「過去のスタンプ」、ラリー削除（確認ダイアログ付き）。スタンプ一覧と目標数なし。

目標:

```
‹ ホーム

今年会った研究者          人
12 / 20                    ← 目標なしなら「12」だけ

9月20日 11:40
メモがあれば一行

9月18日 19:02

9月2日 8:15

[ 過去のスタンプ ]
```

- 一覧は新しいものから過去へ
- メモは一行プレビュー。全文はスタンプ詳細
- 「スタンプを押す」は置かない
- タブバーは残す（[design.md](../design.md) IA）

## 出すデータ

- ラリー: 名称、タイプ
- 収集数。目標ありなら `現在 / 目標`
- スタンプ: 日時、メモ（あれば）

スタンプに「誰 / どこ / 何」の別フィールドはない。内容はラリーのタイプと名称で表す。

## 空 / 読込 / エラー

- 空: ラリーはあるがスタンプ 0。「まだスタンプがありません」
- 読込: 一覧が出るまで待つ
- エラー: 読めないときはメッセージ + 再試行。存在しない id は戻るで足りる

## 未決事項

- ラリーの編集は置かない。削除は確認ダイアログ付きでこの画面に置く
- 記録タイムラインからこの画面への入口を足すか
- スタンプ一覧の代わりに、ラリー単位のカレンダーとタイムラインを置くか（置くなら上のレイアウトを見直す）
- 目標達成の特別な演出は今はしない（数が見えればよい）
