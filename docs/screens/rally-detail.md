# ラリー詳細

## 目的 / 対応 Story

そのラリーに押したスタンプを振り返る。上のサマリでこれまでの記録の様子を掴み、カレンダーで記録がある日を見渡し、日付からその日の記録を辿る。下のタイムラインで押したスタンプを新しい順に投稿として見る。投稿は後から編集・削除できる。タイムラインは Album に切り替えると、このラリーの写真をまとめて見られる。収集数も見る。

- S-006 ラリーの内容を見る
- S-008 ラリーの収集数を見る
- S-013 ラリーを編集する
- S-017 ラリーを削除する
- S-025 過去の日付にスタンプを押す
- S-028 ラリー詳細を見やすく、操作しやすくする
- S-032 よく押すラリーをお気に入りにして、ホームの先頭に置く
- S-039 ラリーを一覧で見渡し、使わないラリーをアーカイブして Home から外す
- S-035 スタンプを押すときに写真を最大 4 枚付けられる（投稿の写真マーク、削除で写真も消える）
- S-037 写真を全画面で見て、Logs とラリー詳細のアルバムでも見る（写真マークから全画面、Stamps / Album の切り替え）
- S-043 Stamps と Album を、指についてくるページ送りで切り替える
- S-051 カレンダーを月表示だけにする（左右のスワイプで月送り）

## 入りと出

- 入り: ホームのラリー行タップ、[rallies-list.md](./rallies-list.md) のタイルの名称タップ（`/rallies/[id]`）。Logs の投稿タップ（`/records/rallies/[id]`。Logs のスタックに積む）
- 出:
  - 戻る → 元のタブ
  - 右上の星 → その場でお気に入りを付け外しし、この画面に留まる（[お気に入り](#お気に入り)）
  - 右上の「…」→「Past stamp」→ [add-past-stamp.md](./add-past-stamp.md)（formSheet）
  - 右上の「…」→「Edit rally」→ [edit-rally.md](./edit-rally.md)（formSheet）
  - 右上の「…」→「Archive rally」（アーカイブ中は「Unarchive rally」）→ その場で切り替え、この画面に留まる（[Archive rally](#archive-rally)）
  - 右上の「…」→「Delete rally」→ 確認ダイアログ → 削除して元のタブへ戻る（[Delete rally](#delete-rally)）
  - カレンダーの今日以前の日付 → [rally-day.md](./rally-day.md)（formSheet）
  - カレンダーの月見出し → 年月 Picker
  - 投稿の写真マーク → [stamp-photos.md](./stamp-photos.md)（そのスタンプの 1 枚目から。全画面モーダル）
  - Album のマス → [stamp-photos.md](./stamp-photos.md)（そのマスの 1 枚目から）
  - 投稿の「…」→「Edit」→ [edit-stamp.md](./edit-stamp.md)（formSheet）
  - 投稿の「…」→「Delete」→ 確認ダイアログ → 削除してこの画面に留まる
- 「いま」スタンプはホームのワンタップのまま。過去日はこの画面のメニューか、カレンダーの日付から formSheet で足す

## レイアウト

現状: 絵文字、名称、収集数、月カレンダー（記録日に印、‹ › で月送り）、タイムライン（新しい順の投稿、「…」から編集・削除）、画面下に「Past stamp」と「Delete rally」。サマリ、カレンダーの折りたたみと日付タップ、ヘッダーメニュー。

Album に切り替えたとき（カレンダーまでは同じ）:

```
[ Stamps · 12 | Album · 9 ]
┌──────────┬──────────┬──────────┐
│     [▣ 3]│          │     [▣ 4]│  ← 3 列の正方形。1 マス = 1 日。2 枚以上なら右下に枚数
├──────────┼──────────┼──────────┤     絵文字は出さない
│          │     [▣ 2]│     [▣ 4]│
└──────────┴──────────┴──────────┘
```

- 上から Top（サマリ）、カレンダー、切り替え、タイムラインか Album の順に、1 本の縦スクロールに並べる（インスタグラムのプロフィール画面の形）。下へスクロールすると Top とカレンダーは上に流れて隠れ、切り替えは画面の上端に貼り付いて残る。切り替えより下は 2 ページ（Stamps / Album）のページ送り
- 画面下のボタンは置かない。ラリーへの操作は右上に置く。お気に入りは「…」の左の星ボタン、それ以外は「…」のネイティブメニューに `Past stamp / Edit rally / Archive rally（アーカイブ中は Unarchive rally）/ Delete rally` の順に並べる。Delete rally は destructive 表示
- Top: 絵文字、名称、収集数、サマリ 3 項目
  - 最初のスタンプ日
  - 1 週あたりの平均数 = 収集数 ÷ 最初のスタンプの日から今日までの週数（週数は最低 1、小数第 1 位まで）
  - 最後のスタンプからの日数（ローカルのカレンダー日で数える）
- カレンダー
  - 月曜始まり。いつも月全体を出す（週表示は無い）。行数はその月の週の数（4〜6 行）。画面に入るたびに今月から始める（表示中の月は覚えない）
  - 週の空いたマスには前後の月の日付を薄く出す。押せず、記録の印も出さない
  - 見出し（年月と ‹ ›）より下の、曜日の行と日付が 1 か月分のページ。前の月・今の月・次の月のページが横につながって並ぶ
  - カレンダーを左へスワイプすると次の月、右へスワイプすると前の月へ送る。スワイプ中はページが指について横に動き、隣の月のページがつながって見える。離したとき、幅の 1/4 以上動かしているか速く払っていれば隣の月に吸い付き、足りなければ元の月に戻る（下の Stamps / Album のページ送りと同じ感覚）
  - ‹ › でも同じように横に送る。年月 Picker で離れた月を選んだときは、横に送らずに切り替える
  - 見出しは表示中の年月
  - 見出しを押すと年月 Picker が出て、選んだ月へ移る
  - 記録がある日はラリーの絵文字を出す（件数・濃淡は出さない）。今日は枠で示す。未来の日は薄く出し、押せない
  - 今日以前の日付を押すと [rally-day.md](./rally-day.md) を formSheet で開く
- 切り替え
  - カレンダーの下に `Stamps · 件数` と `Album · 枚数` の 2 つを並べる。件数はこのラリーのスタンプの数、枚数はこのラリーの写真の数。形は [records-timeline.md](./records-timeline.md) と同じ
  - 画面を開くたびに Stamps から始める（選んだ側は覚えない）
  - 切り替えより下はページ送り。動き、切り替えを押したときの移り方、スタンプが無いときは [records-timeline.md](./records-timeline.md) と同じ。画面の左端から右へのスワイプは iOS の「戻る」のまま
  - 縦のスクロールは画面全体で 1 本。ページを替えてもスクロールの位置はそのまま（ページごとには覚えない）
  - Top とカレンダーはどちらを選んでいても同じ
- タイムライン（Stamps）は切り替えの下に、このラリーの全スタンプを新しいものから過去へ並べる（カレンダーの月では絞らない）。1 日分の投稿を 1 枚のカードにまとめ、カードの上に日の見出しを置く（Logs と同じ形。投稿は線で区切り、見出しは貼り付けない）。投稿は SNS の投稿のように、ラリー絵文字のアイコン、時刻、メモ全文（無ければ `no memo`）を出す。写真が付いていれば、時刻の隣に写真アイコンと枚数のマークを出す。マークを押すと、そのスタンプの写真を [stamp-photos.md](./stamp-photos.md) で 1 枚目から開く（読み上げは `3 photos. Show photos` のように枚数を含める）。日付は見出しに任せる。書き方は [design.md](../design.md)「スタンプの日時」
- 投稿は押せない（遷移先は無い）。押せるのは写真マークと「…」だけ
- Album
  - このラリーの写真だけを、その日（端末の日付）ごとに 1 マスにまとめ、3 列の正方形のグリッドに並べる。並びは新しい日が先
  - グリッド全体を 1 つの面として、外側の 4 すみだけを丸める（日のカードと同じ丸み）。マスの角は丸めない
  - マスの写真はその日の 1 枚目（スタンプの古い順、同じスタンプの中は付けた順で最初）。写真が 2 枚以上なら右下に写真アイコンと枚数を出す
  - ラリーの絵文字は出さない（すべて同じラリーのため）
  - マスを押すと [stamp-photos.md](./stamp-photos.md) でそのマスの 1 枚目から開き、その日の写真をすべてめくれる
  - 読み上げは [records-timeline.md](./records-timeline.md) の Album と同じ（枚数、ラリー名、日付）
- 各投稿の右端に「…」ボタンを置き、ネイティブのメニューで「Edit」「Delete」を出す
  - Edit: [edit-stamp.md](./edit-stamp.md) を formSheet で開き、日時とメモを直す
  - Delete: 確認ダイアログの後に削除する。タイムライン、カレンダー、サマリ、収集数から消える。付けた写真もアプリから消える
- 「いまスタンプを押す」は置かない
- 影は使わない。面の色は淡いアクセントとニュートラルのテーマトークンで分ける（値は `tailwind.css`）
- タブバーは残す（[design.md](../design.md) IA）

### お気に入り

- ヘッダー右上の「…」の左に星ボタンを置く。星と「…」はネイティブのツールバーで 1 つのガラスの背景を共有する
- お気に入りでないときは線の星（`star`）、お気に入りのときは塗りの星（`star.fill`）をアクセント色で出す。読み上げは `Add to favorites` / `Remove from favorites`
- 押すとその場で保存し、確認は出さない。画面に留まる。ホームのタイルの並びと印は、ホームに戻ったときに変わる（[home.md](./home.md)）
- お気に入りの数に上限は無い

### Archive rally

- アーカイブしたラリーはホームのタイルと [rallies-list.md](./rallies-list.md) の `All` / `Favorites` から外れ、`Archived` に出る。削除ではなく、スタンプ・お気に入りの印はそのまま残る
- 「…」の `Archive rally` を押すとその場で保存し、確認は出さない（戻せる操作のため）。画面に留まる。destructive 表示にしない
- アーカイブ中は名称の下に小さく `Archived` を出し、「…」の項目は `Unarchive rally` になる。押すとその場で解除する
- アーカイブ中でも、この画面の操作（お気に入り、Past stamp、Edit rally、Delete rally、カレンダー、投稿の編集・削除）はそのまま使える
- アーカイブしたラリーのスタンプは Logs（[records-timeline.md](./records-timeline.md)）とホームの今日のカードと今日のログにそのまま出る

### Delete rally

- 確認ダイアログの見出しは `Delete rally?`、ボタンは `Cancel` と destructive の `Delete`
- 本文はこのラリーのスタンプ数で変える。スタンプも一緒に消えることを先に示す
  - 0 件: `This action cannot be undone.`
  - 1 件以上: `Its 3 stamps will also be deleted. This action cannot be undone.`（件数は `1 stamp` / `N stamps`）
  - スタンプが読めていないとき: `Its stamps will also be deleted. This action cannot be undone.`
- `Delete` でラリーとそのスタンプをまとめて消す。途中で失敗したときは何も消さず、ラリー詳細に留まってエラーを出す
- 消したスタンプはタイムライン、Logs、カレンダーからも消える。スタンプに付けた写真もアプリから消える（確認文は変えない）

## 出すデータ

- ラリー: 名称、絵文字
- 収集数
- サマリ: 最初のスタンプ日時、1 週あたりの平均数、最後のスタンプ日時からの日数
- カレンダー: 表示中の年月、その月でこのラリーの記録がある日付
- スタンプ: 日時、メモ全文（あれば）、写真の枚数
- Album: このラリーのスタンプの写真（一覧用の小さい画像。無い写真は元の画像）を日ごとにまとめたもの（1 枚目、枚数、日付）、写真の総数

スタンプに「誰 / どこ / 何」の別フィールドはない。内容はラリーの名称で表す。

## 空 / 読込 / エラー

- 空: ラリーはあるがスタンプ 0。サマリは値が無い表示（形は S-028 T-002 で決める）。カレンダーは出て記録日が無いだけ。タイムラインは「No stamps yet」。写真が 1 枚も無いときの Album は「No photos yet」
- 読込: 出るまで待つ
- エラー: 読めないときはメッセージ + 再試行。存在しない id は戻るで足りる
