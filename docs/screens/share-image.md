# 共有の画像

## 目的 / 対応 Story

ラリー・月・1 年の記録を 1 枚の画像にして、iOS の共有シートで本人が選んだ送り先に送る。送る前に、送る画像をそのまま見られる。

- S-058 記録を画像にして SNS に送り、見た人が同じラリーを始められる

## 入りと出

- 入り（どれも formSheet）:
  - [rally-detail.md](./rally-detail.md) の共有の行 → `/share-rally?rallyId=`（ラリーの画像）
  - [records-timeline.md](./records-timeline.md) の共有の行、[home.md](./home.md) の先月のカード → `/share-month?month=YYYY-MM`（月の画像）
  - [year-review.md](./year-review.md) の各ページの共有 → `/share-year?year=&page=`（年のまとめのそのページの画像）
- 出:
  - `Share` → iOS の共有シート。送っても閉じても、このシートに戻る
  - 閉じる（シートを下げる）→ 開いた画面
- 値が不正なとき（`rallyId` が数でない・ラリーが無い、`month` が `YYYY-MM` でない・今月より先、`year` / `page` が不正）はシートを閉じる。ラリーが見つからないときと同じ

## レイアウト

```
            ───                     ← グラバー（ネイティブのヘッダーは出さない）
☕ 行ったカフェ                      ← 補足行（accent-strong）。月と年はその年（`2026`）
Share image                         ← 見出し（大）

      ┌──────────────────┐
      │                  │
      │   画像のプレビュー  │          ← 送る画像そのもの（4:5）
      │                  │
      └──────────────────┘

[        ⇪  Share                 ]  ← 主なボタン
```

- 形はほかの formSheet と同じ（[ia.md](../ia.md)）。補足行はラリーの画像ではラリーの絵文字と名前、月と年の画像では年
- プレビューは送る画像と同じもの。画像の形の切り替えは置かない（4:5 の 1 種類だけ）
- シートはアプリと同じくダークに追従する。プレビューの画像はライトの値のまま
- `Share` を押している間はボタンを押せなくする（2 回開かない）

### 画像の枠（3 つで共通）

[brand.md](../brand.md) 3.3 の見た目と、[DESIGN.md](../../DESIGN.md) の Components「共有の画像」の寸法で組む。

```
┌──────────────────────────────┐
│ ┌──────────────────────────┐ │  ← 地: タブの地と同じグラデーション
│ │ ● Rally    Mar 2 – Oct 25 │ │  ← 頭（小さな丸 + 言葉 + 右に補足）
│ │                          │ │
│ │        （中身）            │ │  ← 白いカード 1 枚。違うのは中身だけ
│ │                          │ │
│ └──────────────────────────┘ │
│  ☀ Ato   Look back. It's all there. │  ← 下のマーク
└──────────────────────────────┘
```

- 1080 × 1350 px の png。色は端末のライト / ダークに関係なくライトの値
- 入れないもの: メモ・写真・押した時刻・連続日数・達成率・前の期間との比較

### ラリーの画像

カードの中は上から次の順。

1. 頭: `Rally`、右に期間（最初と最後のスタンプの日付。`Mar 2 – Oct 25, 2026`。年が違えば `Apr 3, 2025 – Oct 31, 2026`、1 日だけなら `Oct 25, 2026`）
2. 絵文字の丸（`card-disc` の塗り、border の細い輪）と、右にラリー名（長い名前は 2 行まで折り返し、それより長ければ省略）
3. 大きな数: スタンプの数と `stamps`（1 のときは `stamp`）
4. 丸: 押した数だけ並べる。ネイビー（`foreground`）で、いちばん新しい 1 つだけ `accent`

- 丸の大きさは数で変える。カードの下の空いた所（1080 px の画像で幅 808 × 高さ 520 px）に収まる、いちばん少ない列の数を選び、丸をそのマスに入れる。1 マスの上限は 160 px。例: 5 個は 2 列・160 px、38 個は 8 列・101 px、160 個は 16 列・51 px、420 個は 27 列・30 px
- 丸は数だけ並べ、日付には並べない（空いた日が見えないように）。並びは古い順で、最後がいちばん新しい

### 月の画像

カードの中は上から次の順。カレンダーの形にはしない。

1. 頭: 月名（`October`）、右に年（`2026`）
2. 大きな数: その月のスタンプの数と `stamps`、その下に `N rallies`
3. マス目: 1 行が 1 ラリー（左端に絵文字）、1 列が 1 日。いちばん上の行に日付（1〜月末。1 日と月曜を少し濃く）。週の切れ目（日曜と月曜の間）だけ少し間を空ける
4. 一覧: マス目の下に線を引き、ラリーごとに「絵文字 + 名前 + その月の数」を 1 列で並べる

| マス                   | 見た目                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| 押していない日         | `foreground` の 10% の面（押していない日を目立たせない。ライトとダークのどちらでも見える） |
| 押した日               | `foreground`（ネイビー）の塗り                                                             |
| その月の最後のスタンプ | `accent`（オレンジ）の塗り。1 つだけ                                                       |

- 1 ラリー 1 日 1 回を前提にし、回数は出さない。同じ日に同じラリーのスタンプが 2 つ以上あっても「押した日」の 1 マス
- 行の並びはその月に押した数の多い順。同じ数ならホームのタイルと同じ順
- 行は 6 つまで。7 つ以上のラリーを押した月は、上の 5 行のあとに、残りをまとめた 1 行（`+3 rallies · 8 stamps`）を置く。まとめた行にマスは出さない。下の一覧も同じく 5 つと、まとめた 1 行
- 大きな数と一覧の数はスタンプの数（同じ日の重複があればそれも数える。Logs の `Stamps · 件数` と同じ数）

### 年のまとめの画像

- そのページの中身を同じ枠に入れる。中身は [year-review.md](./year-review.md)

## 出すデータ

- ラリー: 絵文字、名称、スタンプの数、最初と最後のスタンプの日付
- 月: その月のスタンプの日付とラリー、ラリーの絵文字と名称
- 年: [year-review.md](./year-review.md)

## 空 / 読込 / エラー

- 空: スタンプが 0 のラリー・月・年からは入り口が出ないので開かない。開いている間に全件を消したら閉じる
- 読込: プレビューは出るまで待つ。`Share` は画像ができるまで押せない
- エラー: 読めないときはメッセージ + 再試行。画像にできなかったときはトーストで知らせ、シートに留まる
