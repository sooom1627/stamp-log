# 言語

## 目的 / 対応 Story

アプリの言語を、端末の言語とは別に選べるようにする。

- S-045 端末の言語に合わせて英語と日本語で表示する（T-003 アプリ内で言語を選ぶ）

## 入りと出

- 入り: [設定](./settings.md)の `Language` 行。ルート `/language`（formSheet）
- 出: 選ぶか、シートを下げると設定に戻る

## レイアウト

```
            ───                     ← グラバー
Language                            ← 見出し（大）

╭─────────────────────────────────╮
│ Device language               ✓ │  ← 今の選択にチェック
├─────────────────────────────────┤
│ English                         │
├─────────────────────────────────┤
│ 日本語                          │
╰─────────────────────────────────╯
The app follows your device's language: Japanese for Japanese, English otherwise.
```

- 選択肢は 3 つ。`Device language`（日本語表示では `端末の言語`）、`English`、`日本語`。`English` と `日本語` はどちらの言語で表示していても、その言語の名前で出す
- 既定は `Device language`。端末の言語が `ja` なら日本語、それ以外は英語（[design.md](../design.md)「言語」）
- 行は設定と同じ角丸の面にまとめ、今の選択の右にチェックを出す
- 面の下に、`Device language` の意味を小さく出す

## 動き

- 行を押すと、アプリ全体の文言がすぐその言語に切り替わり、シートを閉じて設定に戻る。再起動は要らない
- 選択は端末に保存し、次にアプリを開いたときもその言語で出す。起動直後に別の言語が一瞬出ることはない
- 選択は端末ごとの設定なので、書き出しファイルには入れない
- 写真権限のダイアログ、共有シート、ファイルや写真の選択などシステムの画面は、端末の言語のまま出る
- アプリ名（表示名）は端末の言語に従う。どちらでも `Ato`

## 出すデータ

- 今の言語の選択

## 空 / 読込 / エラー

- 読み込むデータは無いので、空・読込・エラーの表示は無い
