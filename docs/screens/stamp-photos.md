# スタンプの写真

## 目的 / 対応 Story

スタンプに付けた写真を大きく見る。横にめくってその日・そのラリーの写真を順に見て、閉じると元の画面に戻る。

- S-037 写真を全画面で見て、Logs とラリー詳細のアルバムでも見る

## 入りと出

- 入り:
  - 投稿の写真マーク（[rally-detail.md](./rally-detail.md) / [rally-day.md](./rally-day.md) / [records-timeline.md](./records-timeline.md) / [logs-day.md](./logs-day.md)）→ そのスタンプの 1 枚目から開く
  - Album のマス（[records-timeline.md](./records-timeline.md) / [rally-detail.md](./rally-detail.md)）→ そのマスの 1 枚目から開く
  - ルート案 `/stamp-photos?photoId=`（全画面モーダル）
- 出: 閉じるボタン → 元の画面（スクロール位置もそのまま）

## レイアウト

```
(×)    🔬 今年会った研究者           ← 閉じるボタン。中央にラリーの絵文字と名称
           Oct 10, 8:15 PM           ← 今見ている写真のスタンプの日時

┌──────────────────────────────────┐
│                                  │
│              写真                │  ← 画面の幅いっぱい。縦横比を保って収める
│                                  │
└──────────────────────────────────┘
             ○ ● ○                  ← 点。今の写真を濃く
             2 / 3                  ← 何枚目 / めくれる写真の枚数
```

- 地は黒。テーマ（ライト / ダーク）に関わらず同じ
- 横にスワイプすると前後の写真へ 1 枚ずつ移る。めくれるのは、開いた写真のスタンプと同じ日（端末の日付）・同じラリーのスタンプの写真。並びはスタンプの古い順、同じスタンプの中は付けた順
  - 1 ラリーにつき 1 日 1 スタンプが基本なので、ふつうはそのスタンプの写真だけになる。同じ日に 2 スタンプ以上あれば続けてめくれる
- 見出しの日時は、今見ている写真のスタンプの日時に合わせて変わる
- 写真が 1 枚なら、点と `n / 総数` は出さない
- 閉じるのは左上の閉じるボタンだけ（読み上げは `Close`）。下スワイプでは閉じない
- 写真の読み上げは `Photo 2 of 3` のように何枚目かを含める
- 日時の書き方は [design.md](../design.md)「スタンプの日時」（例: `Oct 10, 8:15 PM`。今年以外は年を付ける）
- 写真の上で拡大・縮小はしない
- 全画面モーダルなのでタブバーは出さない

## 出すデータ

- 開いた写真のスタンプと同じ日・同じラリーのスタンプ: 日時、写真（スタンプに付けた順）
- スタンプが属するラリー: 絵文字、名称

## 空 / 読込 / エラー

- 空: 無い（写真のあるスタンプからしか開かない）
- 読込: 出るまで待つ
- エラー: `photoId` が不正、またはその写真が見つからない（開いている間に消えた場合も含む）なら閉じる。専用エラー画面は作らない
