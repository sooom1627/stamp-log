# 日詳細

骨格（E-004 / S-012）。配置・遷移・空状態まで。

## 目的 / 対応 Story

選んだ日に押したスタンプを見る。同じ日でもタイプとラリーが分かる。

- S-012 特定の日の記録を見る

## 入りと出

- 入り: カレンダーの日付。ルート案 `/calendar/[date]`
- 出: 行タップ → [stamp-detail.md](./stamp-detail.md)。戻る → カレンダー

## レイアウト（骨格）

```
‹ カレンダー

2026年9月20日

11:40  人  今年会った研究者
  メモがあれば一行

19:02  場所  東京の美術館
```

- その日の中は新しい順でよい
- タイプとラリー名を同じ行で識別する

## 出すデータ

- 選択した日付
- その日のスタンプ: 時刻、タイプ、ラリー名、メモ（あれば一行）

## 空 / 読込 / エラー

- 空: 「この日のスタンプはありません」
- 読込 / エラー: メッセージ + 再試行、または戻る

## 未決事項

- 時刻だけの表示か、日時フルか。日がヘッダにあるので時刻だけでよい
